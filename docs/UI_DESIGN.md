整理日期：2026-11-08（正式遊戲統一固定橫版畫布）。本文整理介面與操作規則；配色、邊框與角色卡定案及實作階層見 [UI_ART_DIRECTION](UI_ART_DIRECTION.md)，經濟與資料規則見 [PROGRESSION_SPEC](PROGRESSION_SPEC.md)，模組交接見 [PROJECT_CONTEXT](PROJECT_CONTEXT.md)。

## 正式遊戲的固定畫布

首頁、旅程與獨立戰鬥入口統一使用1600×900（16:9）的內部場景。外層依實際可用視窗與安全區等比縮放，置中留黑邊；直向視窗將整個場景順時針旋轉90度，無需依賴瀏覽器方向鎖定。視窗尺寸、方向或網址列高度改變時只調整外層，保留既有旅程。

彈窗、popover、Loading與戰鬥iframe都位於同一個內部場景，使用固定座標；滑鼠／觸控由瀏覽器原生轉換座標，不各自套縮放。外層尺寸改變會取消進行中的拖曳，避免在轉向後誤提交。按鈕、間距與文字遵循同一版面，不另外因手機寬度重排。開發工坊不套此畫布，首頁「開發工坊」直接開啟頂層頁面。

下列既有「窄版」CSS描述保留給工坊嵌入及較窄元件視窗；正式手機遊戲的內部視窗仍固定1600×900。瀏覽器測試以 `tests/browser/fixed-viewport.cjs` 的桌面／手機橫向／手機直向流程為準，桌面Edge觸控模擬不代表iOS／Android實機驗收。

## 戰鬥控制美術

戰前可直接拖曳卡片調整站位，不必先開整備。旅程僅我方、工坊雙方，滑鼠與觸控皆可；點擊仍看詳情。拖動顯示來源淡化、落點框與跟隨指標的完整角色卡，沿用整備／商店的抓取偏移及半透明預覽，尺寸維持原卡並保留多格寬度。預覽放入 top layer，避免被陣列捲動區裁切，不攔截落點或取得焦點；放開、Escape、取消、失焦、視窗縮放及重設均清除。放到陣列外取消；開戰後即使暫停也不能拖。多格完整搬移、不同寬度沿用共用交換規劃，保留星等／法則、不合成。工坊另有本頁暫存的敵方極式選單，可在上方畫面查看及試放。

旅程菁英／BOSS 的「敵方」標牌右側分隔線區加入敵方極式圓框，呈現自己的圖案與冷卻；hover／鍵盤聚焦可看說明，手機可點按查看，不能手動代替敵方施放。一般戰鬥不顯示該圓框。敵方圓框為 54px，使用現有圓框及技能圖案；見 [戰鬥規格](BATTLE_SPEC.md)。

顯示敵方圓框時，陣列捲動區內額外預留14px上緣，避免54px圓框超出30px標牌而被裁切；沒有圓框時不加留白。桌面及手機都需確認圓框完整位於捲動區內，且不與開始／暫停按鈕重疊。

各畫面的說明彈窗可點擊外側或按 Esc 關閉。地圖資源欄和商店重骰與水晶之間都顯示回響等級。滑鼠指向或鍵盤聚焦時顯示本局等級與 SR／SSR／UR 基礎機率，按當前回響權重換算。商店離開按鈕旁的問號開啟商店說明。戰鬥速率旁的問號開啟戰鬥說明，並暫停進行中的戰鬥，關閉後可手動繼續。

戰鬥統計與返回戰鬥結果按鈕共用已定案紙框，與速率按鈕同為48px高，寬156px容納切換後的長文字；文字與底圖分離。仍僅在我方勝利或平手後提供，切換只改顯示、不改結算。

戰鬥目前採4「裂白衝擊」背景（取代原7號，正式檔background-fracture-4.png）。敵方標牌在敵隊上方、我方標牌在我隊下方並靠左，兩隊之間不放標牌；上方維持倒數在上、開戰在下，開戰靠近敵隊石板；技能圓框桌面164px、窄版152px（均較初版放大兩倍），桌面技能、速率與整備按鈕一起上移，頂緣靠近我方石板。技能圓框再單獨上移28px，桌面略壓住我方石板下框，技能圖與冷卻環同行，左右文字與速率／整備不跟著移動。技能圓框左右直接排「極／式」，不加紙牌。中央圖案來自技能自己的imagePath，空白／缺圖沿用既有符號，冷卻以深灰底軌及灰藍SVG弧獨立顯示，隨進度填滿、暫停停止。速率與整備共用紙框且可見高度同為48px，700px以下技能與右側控制改分上下兩列；戰前才能整備的時機不變。素材及驗證見 套用紀錄。

## 設計方向

正式遊戲以沉浸感為主：先移除不必要的文字，再依實際遊玩中不清楚的地方逐步補回。保留神秘暗黑背景與細長角色圖片槽，淡化容器邊線、空格與裝飾標籤，不把遊戲畫面做成設定表單。角色素材另行提供，沒有圖片時保留空槽。

- 常駐資訊只保留當下決策需要的名稱、資源、價格、血量與控制；詳細能力按需查看。
- 不顯示操作成功、拖曳取消、放開以搬移／交換等一般紀錄；仍保留操作失敗、無法開局與技能失效等必要回饋。
- 星等使用同款 approved-v1/star.png；戰鬥／整備／商店／戰利品角色卡右上直排 1～6 顆，移出名字列；起點與右側內縮依職業／階級的 PNG 內窗計算，視窗縮放時重算；窄版依可用高度收緊間距／大小，姓名與數值區保留星列避讓空間，詳情姓名旁使用同款 PNG 橫排。詳情職業使用塔形／交叉重刃／子彈／十字圖案；可由版面判讀的佔格數不重複寫成文字。
- 圖像、拖曳落點與停用狀態負責提示；不要重新加入每個區塊的長篇教學。
- 編輯器需要欄位說明、補值紀錄與試打紀錄，不套用正式遊戲的全面刪字規則。工坊預覽、獨立戰鬥與正式旅程仍有不同資料及結算邊界。

## 首頁與地圖

首頁僅保留MiniMajo主標題與START入口，移除「長夜之契」副標題及左上重複首頁連結；本機右上保留開發工坊。右側CSS月亮符陣緩慢漂浮，三顆星各自隨外圓（順48秒）、中方框（逆36秒）與內圓（順24秒）旋轉，星點明暗循環，系統減少動態效果時靜止。按下START後約2.7秒轉場：標題與按鈕向左淡出，符陣移至視窗中心放大，月亮暗面覆蓋亮面，全畫面淡黑後銜接黑底Loading再導向play.html；重複點擊只進入一次，返回首頁會復原。減少動態效果時略過位移與月蝕，直接顯示黑底Loading後進入遊戲。進入旅程後，左上以離開圖示返回首頁。右上資訊列向內縮。回響與水晶的圖示和數值共用深藍金邊資訊框，旁邊是沿用戰鬥樣式的整備按鈕和旅程說明問號。

地圖為主要畫面，移除常駐詳情側欄、圖例、座標、規則長文、設定補值提示與下方一般動作 log。右鍵拖曳旋轉六角地圖。霧層位於地板與事件立板後方，並延伸至視窗外以柔化兩側邊緣，深灰石紋固定於畫面後方。讀取補值機制仍存在，原始 localStorage 不會因讀取而被覆寫；遊戲進度仍沒有持久存檔。

正常及脆弱地板採 A 款灰石，隨鏡頭旋轉及縮放。戰鬥、菁英、終點、營地及商店以朝向玩家的分色立板（灰褐戰鬥、暗紅菁英、黑黃 BOSS、深藍燭夜、孔雀綠商店）標示，同距離下菁英大於普通戰鬥，BOSS 最大。戰利品越少立板越暗。事件消耗後只留地板，脆弱格崩塌後顯示碎石缺口。

戰利品「選擇魔女」的整備入口共用地圖的紙框與書本圖示。

## 整備與角色資訊

儲存隊伍在上、出戰隊伍在下，各十格；保留出售拖放區。移除「旅途整備」標題、隊伍格數、取消選取與拖曳過程說明。

整備與商店角色卡採滿版等比例裁切圖片，下方用半透明深色漸層疊資訊；採戰利品定案的四職業 PNG 外框、種族／屬性圖示、名稱及右上逐顆直排星列 與兩欄最大血量／攻擊力，職業由框形表示，不另列職業圖示或佔格數。商品另列金幣圖示與價格；不顯示戰鬥失衡或行動量條。石板不直接縮成卡片區大小；卡片外側另保留石板包覆區，外擴區不列入十格拖曳座標。整備／商店卡與戰鬥、戰利品共用 css/card-geometry.css 比例（單格 134:288，隊伍零格距、多格寬度按佔格倍增，戰利品選項保留原比例），高度隨十格隊伍寬度等比調整，商店三排同時顯示，依視窗高度限制總寬；桌面主要區域不需上下捲動，窄版保留橫向捲動。技能按鈕只顯示技能名稱，未裝備時顯示「選擇極式」；選單移除條件教學與「不裝備極式」，沒有符合技能時仍保留空狀態。新旅程不自動裝備技能，選單列出全部符合出戰條件的技能，由玩家選定；原技能失效後清空，不自動換裝。技能不再提供優先度。

整備點擊角色開啟置中詳情彈窗，不再顯示下方角色說明。搬移、交換與同角色同星等合成使用拖曳，最高六星；商店商品可直接拖到符合合成條件的自有角色，顯示「放開購買並升星」，放開後扣商品價格並升一星，滿隊亦可使用。保留目標實例、位置及雙方全部法則；金幣不足、不符條件或驗證失敗時不成交。購買到空位及領獎仍不自動合成。

多格卡拖曳以圖片卡片的左緣計算實際起始格，支援逐格位移，包含部分重疊自身原佔位的移動。落點框顯示精確範圍；交換必要時挪動鄰角，但先驗證完整配置、無解時回到原狀。空位仍需按完整佔位判斷，不能將多格角色後續的 null 當作可用空格。

詳情彈窗使用獨立的 4:5 固定頭像區，不依一至三格佔位改寬。角色基本屬性的「詳情圖片檔名」指定專用素材（建議 800×1000）；留空或缺圖先沿用卡圖，再失敗顯示預留槽。詳情彈窗顯示圖片、深色單行名稱＋星星框、能力、客製說明與法則，戰鬥中另顯示即時狀態。新版已套「角色詳情」切角超框標題、羊皮紙曲線外框，以及五張定案透明 PNG 的肖像框、姓名牌、漸淡油墨分區標題與兩種分隔線，不顯示 CHARACTER、陣營格位、開戰／暫停教學及角色懸停摘要。分類以職業／種族／類型／階級四列值呈現；每列左側共用對齊的深藍 PNG，職業採交叉重刃／高速子彈／塔形／十字，階級為橫紋獎章，行動間隔用沙漏、倒地時間用側倒人形、移動距離用繫帶長靴；失衡沿用戰場裂環，失衡加成另用右下疊上升箭頭並鏤空邊界的裂環，護盾共用守護塔形；戰鬥詳情顯示攻擊力、治療力、護盾力的加成後總值，以及狀態秒數／層數加成，省略佔用及下次行動，護盾放在血量下一行；其餘能力名稱及即時數值保留。基本能力與行動效果同排等高，使中間分隔線延伸到整排底部。主標題與肖像固定，右側整區捲動；窄版肖像在上、資訊在下捲動。無狀態時法則跨右側兩欄，無法則隱藏。行動效果維持純文字；戰鬥狀態已共用22枚定案彩色透明PNG；法則以32px符文圖示＋名稱為首行，下方縮排以「－」顯示法則快照的敘述，每個非空換行一條，重複法則逐份列出；圖案使用該法則imagePath，空值或缺圖顯示通用符號，空敘述顯示「尚未填寫效果說明。」。商店是例外：點擊保留選取，桌面右側／窄版下方顯示介紹，不開詳情彈窗。

### 客製技能說明

角色與極式的 description 最多 2000 字，可留空、換行。編輯器角色行動效果與極式施放效果欄位提供編輯；原本程式生成的效果說明改為逐行預設值，不再用分號擠成一行。

缺少、型別錯誤或超長的欄位由讀取補值並記錄，不因此捨棄整份資料或覆寫原存檔。正式畫面的角色詳情、技能選單及戰鬥技能提示使用客製文字。這是固定文案，不隨升星、法則或效果修改自動改寫，編輯效果時需同步維護說明。

## 商店

商店背景使用全視窗，中央隊伍本身水平置中，左右保留等寬側欄。左側直排依序為商店標題、離開按鈕、垂直置中的角色／法則分頁、下方重骰及金錢；整條側欄高度依右側隊伍內容收合，標題與金錢靠近隊伍區上下緣，不貼整頁置頂／置底。出售區與法則商品列緊接儲存隊伍上方，整組在畫面中央排列；右側固定介紹欄，不因介紹使隊伍重心偏左。垂直分頁支援上下方向鍵。買賣及重骰同步更新商店與地圖金幣。沿用 dialog 的鍵盤焦點與 Escape 關閉行為，明確離開或 Escape 皆按原規則消耗事件。

桌面左側保留三排十格，右側固定顯示選中角色的技能與法則；介紹不再向下撐開畫面。`css/scene-layout.css` 依可用寬度和高度共同決定隊伍寬度，維持 134:288 卡片比例與石板外緣，1366×768、1920×1080 不需上下捲動主要操作區。法則分頁保留四件商品與中央角色框，下方兩隊；法則商品列固定占用「出售區＋角色商品石板列（含外緣與間距）」的相同總高度，切換分頁不改變整體高度、置中位置及兩隊座標。長敘述僅商品內部捲動。900px 以下改下方固定介紹區，隊伍與法則保留局部橫向捲動；高度低於 600px 保留局部捲動備援，不硬縮到無法操作。

法則分頁仍顯示兩隊，每次固定 4 個商品、左右各上下堆疊兩張，中央預留三格寬的裝備角色區；一／二／三格角色均以相同大小4:5詳情肖像置中，切換對象不推移法則。法則選項採A羊皮紙底框，圖案窗為正方形，圖片等比容納。右側在基本能力與技能效果後逐條列出全部已裝備法則完整敘述與永久屬性，空敘述以被動效果補顯，內容多時在紙框內捲動。法則圖案、名稱及價格集中頂列，敘述使用下方完整寬度；窄版可橫向捲動，購買直接裝備給指定實例。法則框顯示敘述，不另列「法則被動」一行；效果說明由敘述維護。角色與法則的 12 種戰鬥被動已生效；6 種非戰鬥時機已移除，詳見 README「戰鬥法則被動」。關閉商店會消耗該地圖事件，回訪只可通行。

## 戰鬥

獨立示範、工坊試打及正式旅程共用以下戰鬥版面，不以旅程模式切換外觀。內嵌只隱藏頁首導覽；重新試煉依用途保留於示範與工坊，旅程由父頁管理結算。

倒數位於敵方上方並水平置中，下一行為置中的開始／暫停／繼續按鈕，再下方為敵方陣列。我方陣列下方一行將極式按鈕水平置中，速度＋整備同列靠右，緊貼隊伍石板右下緣。整備只在旅程開戰前提供，沿用既有準備握手；保留速度與統計控制。戰鬥結束先以全畫面模態演出顯示 VICTORY／GAME SET，持續停留等待點擊，Escape不關閉。勝利確認後才結算並開啟戰利品；敗北確認後直接退回地圖的戰鬥前一格。平手確認後沿用原結算並可查看統計，再由「返回地圖」離場。勝利未領完獎勵時，原開始按鈕的「返回地圖」會先回領獎，領完才能離場；父頁返回入口仍只作內部處理。獨立展示與工坊確認演出後顯示「試煉結束」並保留原重試／統計。

正式旅程進入戰鬥後覆蓋整個遊戲畫面，內嵌戰鬥頁占滿可用高度，整備已移至頁內我方下方，父頁僅保留返回流程的內部處理，畫面使用戰鬥主按鈕返回。共用戰鬥頁以視窗寬高限制陣列尺寸，陣列容器最大 1348px，卡片維持接近整備的尺寸上限；背景採 cover 等比裁切，不隨視窗比例拉伸。控制列緊鄰隊伍上下緣，中間雙方各十格；桌面主要操作無上下捲動。窄版保留陣列區內橫向捲動，角色詳細能力仍按需開啟。

角色圖等比例裁切鋪滿卡片，資訊以半透明深色漸層疊圖。套用同伴卡的 PNG 外框與資訊列：標頭同一行為種族／屬性圖示、角色名；星等獨立在卡片右上逐顆直排，職業由框形表示；名字下方依序為整行紅色血量＋灰藍護盾共用條、整行灰褐色失衡條、攻擊力／攻擊距離各半。有護盾時顯示 HP+護盾/最大HP，護盾0時顯示 HP/最大HP；條長分母為 max(最大HP,HP+護盾)，紅血量在左，灰藍護盾緊接其後，未填滿段在右；失衡維持目前值／上限。狀態列不再重複顯示護盾徽記。狀態圖示從名字上方左邊開始，滿行再往上一行左邊接續，不再限制只顯示三個；名字與下方資訊固定位置。狀態保留為小圖示／數字，護盾併入血量條，詳情可讀完整內容。行動進度獨立覆蓋整卡，由下向上亮起；行動後直接重新累積，不額外切換亮度、底色或遮罩；暫停時跟隨 tick 停止，減少動態效果時停用補間。空格與死亡後空位改為透明，整排十格共用同一張石板底圖；全滅時石板仍保留，不顯示空位文字，也不作為可點擊目標。

共用版面隱藏遭遇標題、隊伍人數與格數、格位標記、技能問號與戰鬥頁紀錄。旅程另外清空準備及結束敘事，由父頁顯示結果與戰利品；獨立示範與工坊仍顯示操作狀態及勝負訊息，工坊父頁保留試打紀錄。勝利金額移入戰利品流程。

我方下方靠右的整備只在開戰前提供，取代撤退；開戰後即使暫停也不能整備。關閉整備時更新我方隊伍與技能，保留原先抽出的敵隊，不結算獎勵；出戰隊伍為空則保持開戰鎖定，允許再次整備修正。

技能效果由懸停／聚焦技能按鈕顯示，移除獨立問號。未裝備時名稱留白、技能按鈕壓灰停用，不增加說明訊息。

實際補血時卡圖向上掃柔綠光、新增護盾時卡片外緣冷藍光圈短暫擴散；滿血溢補及0增量不播放。閃避只浮MISS文字，不側閃或移位。極式每次充能剛就緒時圓框短亮、微放大回彈一次，不循環提示。四項回饋跟隨暫停／倍速，減少動態效果改為靜態MISS並停用其他新動畫，資訊列保持清楚。

戰鬥右上新增「音效／靜音」紙面切換，預設開啟並記住靜音偏好；位置在計時器右側，不加入石板右下的控制列。首次操作解鎖音訊，暫停、背景分頁、查看詳情及統計停止聲音；群體命中短音合併節流，倍速不改音高。減少動態效果與靜音各自獨立。

音量由Config的「戰鬥音效」區設定0～100%，預設60；保留0為無聲，於試打重設／新旅程載入。死亡以不可操作殘影向下淡出約380ms，格位即刻可用；跳躍約180ms、互換約140ms快速連續位移，互換雙方走不同短弧線以辨別交換。普通移動亦短滑，暫停／倍速同步；統計／重試移除殘影，減少動態效果直接換位，視窗縮放取消舊尺寸位移。

戰鬥 HP 紅條立即反映傷害，淡紙色缺血殘影短暫追上；補血追平取消、護盾比例改變同步換算。直接命中時卡圖短閃，純護盾吸收冷藍、傷及 HP 暖色，資訊列不閃。倒地門檻觸發時整卡下沉回彈、失衡圖示彈動一次，再保留原倒地濾鏡；倒地下沉優先於同時的攻擊彈動。新回饋跟隨暫停、倍速及減少動態效果，統計不播放。

時間歸零時，計時器轉暗紅並開始顯示正向超時時間；中央「侵蝕加劇」短暫浮現，之後只保留暗紅邊緣及實際超時扣血脈衝。覆層不攔截點擊，角色資訊與操作保持可讀；暫停／倍速同步，減少動態效果改為靜態提示。結束與統計不顯示覆層。現階段使用系統楷體與 CSS，專用美術字尚未定案。

速率旁新增「手動／自動」極式切換，預設手動；自動只在戰鬥播放中、極式就緒且原有施放條件成立時釋放我方極式。按鈕沿用紙面外框，文字及 aria-pressed 同步切換；整排靠齊隊伍石板右緣，整備隱藏後仍維持同一右側基準；較窄石板下的長控制列下移避開極式，1000px 以下獨立下一列。

查看角色會暫停正在進行的戰鬥，關閉詳情後自動恢復；若原本就是手動暫停，關閉後仍維持暫停。已結束戰鬥不會恢復播放，頁面隱藏時也不自動恢復。

## 戰利品與戰鬥結果

勝利先開啟戰利品入口，提供「水晶」與「魔女」，兩項都要完成，並非二選一：

兩個入口按鈕完成後停用，文字維持「水晶」「魔女」，不追加勾號。獲得彈窗標題為「獲得水晶」。

1. 金幣在勝利結算時只入帳一次；點「水晶」以共用水晶圖示＋數字顯示本場金額（不加正號或金幣字樣），確認或關閉小彈窗表示已查看，不再次加錢。
2. 點角色開啟同伴三選一，卡片使用四職業三階 PNG 邊框、滿版圖與資訊漸層，依戰鬥比例等比縮放，基準高 288px，依 space 算實際寬度（1／2／3 格為 134／275／416px），彈窗依選項總寬收合、不預留十格空間；卡區沒有獨立捲軸，置中並在窄版自動換行，卡片多排由整個彈窗內容區上下捲動；介紹區一開始顯示分隔線並固定預留 182px，長文以內部拖曳／觸控／滾輪上下閱讀，隱藏捲軸，選角不改變高度；第一行種族／屬性版畫 PNG 圖示、名字與右上直排星列，第二行最大血量／攻擊力各半，不加數值小框；資訊使用紙色襯線字，字級依實際卡寬調整；職業以上半框形表示，rarity 選擇舊鐵／亮銀／亮金材質，不更改佔位資料；選取以卡片上緣浮動版畫箭頭表示，下方介紹使用「技能效果」標題；點卡只選取並顯示下方角色介紹，另按「確認選擇」才領取。尚未選取時確認停用。
3. 滿隊領取失敗保留原選項與目前選取，可開整備清出空間再按確認；空獎勵池需要確認。
   有角色選項時另提供「放棄＋10」與共用水晶圖示的按鈕，不需先選卡，立即放棄本批角色並額外入帳10水晶；按鈕與整備、確認選擇同列，窄版自動換行。原戰鬥水晶確認流程保留，空角色池不顯示此選項。
4. 兩項完成後入口自動關閉，才能繼續探索或開始新旅程；完成前不提供「返回戰鬥」略過流程。

平手沒有金錢或角色獎勵，但消耗戰鬥格並可查看統計；敗北確認後退回前一格，重新走入未消耗敵人格可再挑戰；原敵隊與鎖定獎勵保留。目前終點平手也結束旅程、不給勝利獎勵，這是沿用平手消耗格位規則的暫定處理。

### 統計版面

勝利與平手可查看統計，死亡角色仍按開場位置列出。移除統計長篇解釋，傷害／護盾／治療／行動四項貼近名字列正上方置中、由該列向上展開，不再貼頂框，以免不同職業框裁掉資訊；統計模式暫隱狀態圖示避免重疊。保留原角色卡與血條，不增加卡片高度。雙方陣列、角色與空位在同一螢幕尺寸使用一致高度，避免全滅後切換統計造成版面跳動。

## 彈窗關閉規則

一般遊戲彈窗移除關閉 X，以點外側或 Escape 關閉；按下與點擊都必須發生在外側，從內容拖曳出界不應誤關。法則目標的清除符號是清除選取，不屬於彈窗關閉鈕。

| 彈窗 | 關閉後行為 |
|---|---|
| 整備／角色詳情 | 返回原操作位置；戰鬥詳情依開啟前播放狀態恢復 |
| 商店 | 關閉並消耗商店事件 |
| 選擇同伴 | 外側或 Escape 返回戰利品入口，不丟失選項；沒有「返回戰利品」按鈕 |
| 金錢收據 | 確認、外側或 Escape 完成金錢查看，返回入口或完成領獎 |
| 戰利品入口 | 強制完成領獎，不可用外側或 Escape 略過；兩項完成後自動關閉 |

## 維護與驗證

共用詳情由 js/character-details.js 與 css/character-details.css 負責；外側關閉由 js/dialog-dismiss.js 負責；整備／商店在 js/expedition-ui.js，領獎入口在 js/journey-reward-ui.js，戰鬥呈現在 js/game.js、css/battle.css 與 css/battle-cards.css，暫用圖示在 js/ui-icons.js。

驗證範圍與最近一次執行紀錄統一見 [UI_ART_DIRECTION.md](UI_ART_DIRECTION.md)「驗證狀態與待完成項目」。不要沿用舊版測試數量宣稱目前全套通過；圖片／CSS 的無頭瀏覽器檢查也不等於完整旅程 E2E。橫向捲動、iframe 載入時序及拖曳手感仍需實際瀏覽器驗證。

目前整備入口統一為 6B 去框書本圖案，60×60px 點擊區，保留「整備隊伍」的可存取名稱與懸停提示。獎勵選取標記採低彩度礦石碎晶 v2（48×58px、top -29px，約一半覆蓋卡片上緣、上方留白 64px）、介紹分隔線採版畫藍灰 v2（18px 高、端點固定 60px）；素材及樣式數值以 UI_ART_DIRECTION 和 CSS 為準，舊候選頁不是目前實作規格。

整備的「裝備極式」會開啟疊在整備上方的獨立彈窗，不再向下展開或改變整備視窗位置。僅列出符合目前出戰隊伍的技能；選項只顯示圖示與名稱，最多約三列，其餘上下捲動；點選後在獨立區域顯示完整技能說明與冷卻時間，按「確認裝備」才提交並返回整備。未選取時確認停用，取消不提交草稿；再次開啟以已裝備技能為初始選取。圖案使用技能 imagePath，留空或載入失敗時顯示通用符號。點外側或 Escape 只關閉技能彈窗並回焦點至原按鈕，不更動裝備；工坊保留卸下技能操作。技能清單與說明各自獨立捲動，切換技能將說明回到頂端。正式旅程、工坊與 UI 試看共用此行為，商店仍不提供技能裝備。
