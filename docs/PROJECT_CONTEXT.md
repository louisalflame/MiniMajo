2026-11-07 目錄清理後：根目錄保留四個正式 HTML、啟動程式與固定 JSON；25 個樣式檔在 css/，正式 62 張角色圖及 124 張 UI 圖在 assets/。三張定案畫風參考保留在 docs/art-style/，網路角色參考與全部歷史角色候選已刪除；UI 示意、比較頁與一次性輸出亦已刪除，僅保留20張工具來源、4份來源JSON與彙整的採用／提示紀錄於 docs/ui-style/。

所有獨立試看頁與專用控制器已退役，整備／商店卡框改由正式 play.html 載入記憶體測試，獎勵功能沿用正式 JourneyRewardUI。舊預覽專用測試退役，正式引擎及資料驗證保留。新測試輸出一律寫入 tmp/，避免重新累積到 docs/。詳細清理與本機還原封存見 [整理紀錄](maintenance/cleanup-2026-11-07/README.md)。

## 3. 已實作的旅程

1. 新旅程建立地圖與隊伍，依 Config 的固定初始出戰十格配置建立角色實例，初始儲存隊伍固定為空；角色庫排序不影響編隊。配置引用失效、重疊或超界會阻止開始，不自動補角或換隊。
2. 地圖上可隨時整備。點擊相鄰格直接前進，動畫中與待完成事件期間阻擋連點移動。脆弱地板離開時崩塌，之後禁止進入。
3. 商店共享本局隊伍與金幣；首次進入自動開啟，關閉視窗即消耗，回訪只能通行。
4. 戰鬥帶入所有出戰角色、原始站位與選定技能；每場全員滿血開始，上一場死亡不影響出場，儲存角色不參戰。
   固定資料「基礎極式」已修正傷害搜尋組為隨機敵人；原先空 targets 使主效果及後續治療皆略過。傷害仍為施放者目前 HP × 0.5，治療修正為受治療同伴最大 HP × 0.2。已用實際儲存技能重現修正前無效及修正後傷害／治療，並通過 41 項相關 Node 測試；本次未操作瀏覽器戰鬥。既有旅程仍保留原快照。
5. 勝利結算金幣並完成節點，開啟金錢與角色戰利品入口，該階級應領的金錢與角色項目皆完成後才可繼續探索；不回寫戰鬥血量，戰場上的位置移動不覆寫整備站位。
6. 一般／菁英／BOSS 勝利金幣依 Config，預設 40／90／150；一般／菁英依鎖定衰減階級乘金幣比例並提供 3／2／1／0 個角色選項；BOSS 維持全獎勵。
7. 敗北保留開戰前狀態，不發獎，可整備後重試；平手不發獎但消耗戰鬥格，終點平手則旅程結束。正式介面不提供撤退，整備僅限開戰前。
8. 營地（rest）抵達時自動免費提升一級回響等級並消耗；到達設定上限也會自動完成，不再要求按鈕。
9. 終點進入 BOSS 戰，勝利通關；平手無獎勵並結束旅程，兩者皆可開始新旅程。

起始金幣 300、獎勵數量、半價賣回、失敗不扣資源、每場滿血及初始隊伍分配，
皆是目前原型規則，仍可調整，不代表完成遊戲平衡。

### 成長、公式與戰鬥顯示

職業 jobGrowth、種族 raceBonuses、階級 rarityBonuses 及法則 stats 共用十一欄。既有九欄外新增 statusDurationBonus（0.1 秒）與 statusAmountBonus（整數），預設 0。星級只累加起始星之後的增量，種族／階級各套一次，法則按份數相加。完整欄位與上下限見 README「成長與狀態加成」。

傷害、治療、護盾的對應攻擊力包含基礎值、同類成長／分類／法則加成及戰鬥狀態。角色普通行動與固有被動可乘倍率，極式與法則被動使用公式與常數。增減失衡倍率用基礎 attack，增加失衡另加 outputBonuses.posture。公式 self／enemy／target 的 attack 也指基礎值。

角色詳情的狀態秒數／層數加成顯示有正負號的總值，秒數另標「秒」，零值亦列出。欄位提示說明它們分別加到技能的持續秒數與施加量。

狀態施加量算完再加狀態層數加成，秒數型持續時間加狀態秒數加成。普通行動、固有／法則被動及極式都取實際施放者的兩項加成。固定規則如閃避、嘲諷不增加施加量，次數／永久不加秒數。例 HP 10、self.hp*2、10 秒，搭配 +3 層數、+2 秒，結果 23 點與 12 秒。

outputBonuses 保留 damage／heal／shield／posture，兩項狀態加成另存角色同名欄位，ItemDB.runtime 驗證並保留至 iframe。成長表單、星級預覽、戰鬥詳情及共用角色詳情提供對應數值。戰鬥卡攻擊力為傷害總攻擊力，詳情另列治療力、護盾力與兩項狀態加成。

角色庫驗證會建立 growth、raceBonus、rarityBonus 快照，整備／旅程從原始快照重算，避免合成或重複裝法則累加兩次。固定資料透過 editor-server.cjs 寫入，外部舊備份與缺欄位相容處理集中在 js/saved-data.js。

角色圖片新增 `detailImageFile`（預設空字串），與 `imageFile` 同樣只接受 assets/characters/ 內的檔名、最多 120 字元。編輯器基本屬性可編輯詳情圖片，建議統一 4:5（800×1000）；整備及戰鬥詳情優先使用專用圖，未指定／載入失敗退回卡圖，再失敗保留預留槽。隊伍卡仍使用 imageFile。角色複製、星級／法則能力副本、本局與戰鬥快照、完整備份保留此欄位；舊檔缺少／型別錯誤／不合法逐欄補空值並記錄，不拒絕整個角色或改寫來源。tests/browser/detail-art.cjs 使用暫存固定 JSON 與隔離 Edge 驗證儲存重載、複製、390px 編輯器及整備／戰鬥詳情的空值、缺圖回退；未修改正式 JSON 或替角色指定新素材。

美術交付以兩張為完整一組：依佔格製作的卡圖與統一 4:5 的詳情頭像。詳情圖回退卡圖僅為備援；友萌已設定 `imageFile: youmeng-1slot.png` 與 `detailImageFile: youmeng-detail.png`，兩張素材皆已確認並套用。比例與製作流程統一見 ART_STYLE.md。

角色主要欄位：
`id,name,imageFile,detailImageFile,description,race,affinity,stars,rarity,job,space,maxHp,attack,attackRange,moveDistance,movement,cooldown,effects,shopPrice,shopWeight`。 attack 預設 10（0～10000），attackRange 預設 1（1～10）；舊資料缺少距離取原效果最大合法 range，逐欄列出補值而不覆寫原檔。
種族為人類／獸人／機人，類型為物理／精神／魔法，星等 1～6，階級 SR／SSR／UR，
職業守護／破陣／飛襲／支援。`space` 允許 1～99，但十格陣列必須放得下。
售價、權重允許 0～1000000 整數；售價與權重為必要欄位。

敵隊結構：

```json
{
  "id": "team-example",
  "name": "範例敵隊",
  "category": "normal",
  "weight": 100,
  "slots": ["short-sword", null, null, null, null, null, null, null, null, null],
  "stars": [null, null, null, null, null, null, null, null, null, null],
  "laws": [[], [], [], [], [], [], [], [], [], []]
}
```

`category` 為 `normal`／`elite`／`boss`；`slots` 固定十格，引用角色庫 ID。
另有十格 `stars` 陣列，每格為指定星數或 `null`（依角色起始星數）；新建設定預設為全 `null`。
敵隊編輯器為左側清單、右側設定，各位置可選角色與起始星數至 6 星，顯示 HP／佔位摘要。
可重複使用同一角色，多格角色僅填起始格。角色刪除或變寬可能使已儲存敵隊失效，

### Config 與全域數值

Config 的「倒地行動速度降低（%）」（downSlowPercent）預設 20，範圍 0～100 整數。倒地期間普通行動進度速度乘上 (1−降低比例)，急速／倦怠先計算後再乘倒地倍率。20 代表原速度的 80%，0 無減速，100 停止普通行動進度。僵直仍凍結進度，起身後恢復正常速度，極式冷卻不受此參數影響。舊檔缺少或無效值補20並列修復紀錄，合法0保留。

Config 包含超時開始時間／扣血週期／初始扣血量／成長間隔／每次成長量、基礎倒地時間、初始金幣、三類獎勵、商品數／賣回比例／商店重骰初始及累加費用、失衡門檻／轉換比例／倒地倍率，共 18 項數值。另有 startingActive 十格角色 ID 或 null 陣列，直接指定初始出戰隊伍與位置；儲存隊伍開局固定為空，不提供欄位，可重複角色並建立獨立 instanceId；引用、佔位在 Config 儲存、旅程建立與備份匯入時驗證。多格後續佔位保留 null，錯誤不自動搬移或補角。基礎倒地時間已同步成長、法則、星級預覽、敵隊與戰鬥，允許 0.1～120 秒。保存重置工坊試打及整備商店預覽；旅程與戰鬥使用快照。只有我方有極式；敵方技能等待與提前施技欄位及邏輯已移除，敵方普通行動保留。完整欄位與範例見 README。

### 超時耗損

超時有五項參數：開始時間 X、扣血週期 P、初始量 Y、成長間隔 A、成長量 G，預設 120／1／10／10／10。第一次扣血在 X+P 秒，此後每 P 秒一次；成長從第一次扣血起計，每滿 A 秒增加 G，於扣血時點套用，G=0 不成長。第 n 次傷害為 Y+floor((n−1)P/A)×G。表單提供前四次扣血預覽。雙方同 tick 直接扣血、穿盾，不觸發反擊／激怒／失衡，先於狀態恢復與行動；同時全滅仍平手。

### 法則與角色被動

角色 `passives` 預設空陣列（最多 20 條），與法則共用 `Laws.validatePassives`、`EffectEditor.passiveRow` 與戰鬥事件佇列，角色固有被動支援持有者攻擊力倍率，法則被動使用常數效果。編輯入口在「行動效果與狀態」底部，複製／升星／快照／備份／旅程均保留。每條固有被動與各份法則有獨立連鎖識別。玩家成功使用極式扣 CD 後、效果前觸發 playerSkill，全域通知雙方存活未僵直持有者，不檢查事件角色範圍／屬性；效果自身條件照常。無法施放不觸發。

新增 `js/laws.js`、`js/law-editor.js` 與頂層法則視覺化編輯分頁，儲存鍵 `minimajo.laws.v1`。
法則為 `{id,name,shopPrice,shopWeight,stats,passives}`，永久附掛於角色，與 statuses 不同。敵隊十格 `laws` 各保存完整法則陣列快照。同一角色可重複加入同一法則，每份獨立保留與移除，永久屬性逐份累加後套用既有能力上下限（角色持有份數不再限制為 100，以完整保留合成繼承）；隊伍讀檔、備份匯入及戰鬥均保留重複項目，法則庫定義 ID 仍唯一。
工坊試打雙方每格可加入、重複疊加及逐份移除法則，先套星級再套法則；開戰鎖定，重置後可調整，更換角色清空該格法則，配置只保留於本次頁面。摘要顯示套用後能力，父頁與 iframe 使用相同編隊。傷害／治療／護盾屬性加成僅影響倍率前的攻擊力，不影響戰鬥數值運算群組與常數整數，已套用敵隊並帶入 iframe 戰鬥；角色與法則共用 19 種戰鬥時機；新增 playerSkill「玩家使用極式時」與 dodged「角色閃避成功時」。升星、勝利、地圖移動、休息、購買、販賣 6 種非戰鬥時機已移除，舊檔略過這些被動並列出修復紀錄，不改成其他事件。
局內已可在商店購買法則並直接裝備給指定角色；其他取得途徑與局內移除法則操作仍未實作。戰鬥連鎖規則見 README「戰鬥法則被動」。售價與權重為 0～1000000 整數，0 售價免費、0 權重排除抽選；新建與舊資料逐欄修復預設售價 50、權重 100，讀取列出紀錄且不覆寫原存檔。法則編輯器已改為左側名冊、右側屬性與被動卡片；可新增／搜尋／複製／刪除／儲存。效果沿用 EffectEditor 與 FormulaEditor，法則被動只提供公式與常數，角色普通行動及固有被動可設定攻擊倍率。空庫顯示新增引導，未儲存修改有離開提醒，儲存失敗保留草稿。

### 狀態庫

狀態有正面、負面、中性分類。固定存檔採「永續」前綴，enhanced ID 與資料欄位沿用既有命名。js/statuses.js 的缺庫預設名稱仍為舊「強化」前綴，實際頁面以載入的狀態庫名稱為準。一般狀態只選秒數或行動次數，永續固定至本場結束。施加、同名刷新與永續累加都會產生 statusGained 事件。

新增 dodge「閃避」，固定 `duration:{kind:"attacks",value:1}`、不疊層，不隨秒數／自身行動消耗。狀態作用選為閃避時，數值模式鎖定固定值 1，倍率／公式停用。成功閃避消耗狀態後立即發送 dodged 被動事件，事件角色為閃避者，同次普通行動的多項作用與副效果只觸發一次；角色與法則共用角色範圍／條件及連鎖防護。暫定迴避敵方一次普通行動對自身的所有敵對作用（含副效果），不產生受擊／反擊／激怒；反擊、被動、玩家極式與持續傷害不消耗也不受閃避影響。

固定資料的永續中毒／再生／強化／虛弱／堅硬／脆弱沿用 enhancedPoison／enhancedRegen／enhancedPower／enhancedWeakness／enhancedHard／enhancedFragile ID；`enhanced:true`，效果同原版、數值由技能提供、固定永久至本場結束，同 ID 施加量相加、與原版並存、保留原跳動節奏。一般狀態仍覆蓋數值並刷新時間。狀態表單顯示強化標記與持續時間限制，施加效果鎖定限制並隱藏不需輸入的時間值；自訂狀態可設定 enhanced（預設 false），不可與閃避／速度規則並用，六種內建強化標記固定。舊檔補入缺少內建狀態、逐欄修復並列出紀錄，不改原始檔。

嘲諷（taunt）為固定啟用、無強度數值的一般狀態，可設秒數或角色行動次數，同名刷新、不疊層。僅影響 CD 到時普通行動對敵方的最近單體、最低 HP 數值／比例、最高失衡與隨機一人搜尋：先套原目標條件，再找施放者攻擊距離內、存活且持有嘲諷者；優先選最近者，同距離隨機。無合法嘲諷者沿用原搜尋，不縮減最低血量／隨機等原本不限距離的搜尋範圍。距離沿用完整佔位計算。正對面、全體、我方搜尋、主效果目標／本次事件角色及其左右鄰居不改選；移動、互換、跳躍、被動及手動技能不受影響。每組搜尋獨立選取，組內全部作用共用結果；主／副效果都適用。內建狀態庫新增嘲諷，舊庫讀取逐欄補入並列修復紀錄；其規則固定 value:1，不能使用倍率、公式或強化累加，狀態編輯器鎖定相關欄位。未新增或替換正式狀態圖示。

頂層「狀態」分頁提供名冊、搜尋、新增、複製、名稱與效果卡片編輯。內建 21 種狀態（含嘲諷、閃避與六種永續狀態）以預設資料提供；混亂增加失衡，鎮靜降低失衡，激怒受擊時推進行動進度。
每個狀態可組合 1～8 條作用：每秒 HP／失衡增減、傷害／護盾量修正、普通攻擊反擊、受擊進度推進、僵直及速度調整。
數值模式為施加量倍率、固定值或視覺化公式；速度比例 0.5 代表 50%，受擊進度以秒設定並換算成 0.1 秒 tick，其他數值取整。速度總倍率限制 0～10。激怒預設固定 1 秒，每筆正值敵方直接傷害觸發一次（護盾承傷及技能亦算），中毒與反擊不觸發；以傷害結算前的狀態為準，死亡不推進，進度最多到就緒，最早下一 tick 行動。
公式 self／enemy／target 均指狀態持有者，time 暫為 0；不支援施加者引用。一般狀態持續時間在角色／極式／被動效果中設定，通常可選秒數或角色行動次數。舊設定若為一般永久狀態，載入時補為 1 秒並列出修復紀錄；含速度效果僅限秒數、閃避固定 1 次敵方普通攻擊、永續狀態（enhanced）固定永久。狀態編輯頁明示限制與是否強化，效果編輯器鎖定受限制的持續方式並隱藏不需填寫的數值。
保存鍵 `minimajo.statuses.v1`，格式 `{version:1,statuses:[{id,name,description,imagePath,classification,enhanced,effects:[{behavior,scale|value|formula}]}]}`。原角色／技能存檔仍引用狀態 ID。
狀態選單儲存後更新、工坊試打重置；旅程開局保存狀態庫快照並隨戰鬥訊息傳入 iframe。已附加狀態也保存作用規則快照。
目前不提供刪除狀態，以避免角色／法則的引用失效；狀態庫包含在統一備份中；新建與複製後須儲存才加入名冊。角色與法則戰鬥被動已接入事件執行，非戰鬥時機已移除。

### 儲存相容與逐欄預設值

編輯器現在以專案根目錄 `minimajo-editor.json` 為固定來源。雙擊 `啟動MiniMajo.cmd` 會自動開啟瀏覽器，已有同專案服務時直接沿用；首次啟動服務的視窗請保持開啟。也可執行 `node editor-server.cjs` 後手動開啟 `http://127.0.0.1:4173/editor.html`；服務只綁定 127.0.0.1，不需安裝套件。可用 MINIMAJO_PORT 改連接埠，平常請保持位址不變。直接開 HTML 或使用一般靜態伺服器不能覆蓋固定檔案，編輯器會明確報錯並鎖定編輯。

開啟時先讀取固定檔案，完整補值與驗證成功後才同步到 localStorage 並啟動各編輯分頁；缺檔、JSON 無法解析或無法辨識的完整檔案會阻止載入，不使用空預設資料覆蓋檔案。單欄無效仍逐欄修復並列出紀錄，讀取本身不改寫固定 JSON。localStorage 是同來源頁面的資料快取，不是正式檔案來源；旅程進度仍只在記憶體。

各分頁原有儲存、新增／刪除等已儲存操作，以及地圖與空間上限的即時儲存，會自動將全部已儲存資料排隊覆蓋固定檔案；不包含未儲存草稿、試打陣容或旅程進度。頂部顯示「正在覆蓋」「已同步」或「寫入失敗」，請等到已同步再關閉。失敗保留瀏覽器中的已儲存內容並提供重試，尚未同步時離開會提醒；也可下載備份救回內容。檔案版本衝突需先下載當前資料備份再重新讀取，不會直接蓋掉其他分頁或外部修改。

本機服務只接受固定資料檔的讀寫，保存前驗證、以同資料夾暫存檔完整寫入並同步後替換；失敗保留原檔且清除暫存。每次覆蓋檢查載入時的內容雜湊版本，並將本機請求串行處理。這是編輯工具的本機檔案服務，沒有遊戲後端、帳號或旅程存檔。
`js/storage.js` 的 schema 僅為格式標記，不會因版本不同清除或拒絕資料。`js/saved-data.js` 統一處理讀檔：缺少、型別錯誤或超界欄位逐欄補合法預設，保留其他欄位、角色與資料庫；合法的 0、false、空陣列不會被覆蓋。
每個新增欄位必須同步定義讀取預設值與相容測試。HP、時間、名稱等使用合法預設；角色庫完全空白時建立一筆空白角色供編輯。單庫讀取與預覽不改寫來源；編輯器啟動時則依固定檔案重建瀏覽器快取，表單儲存仍嚴格驗證。工坊頂部提供補值紀錄，不提供手動清空資料按鈕。

### 完整編輯資料備份

頂部保留共用工具列：「下載全部編輯資料備份」提供額外備份；「以備份取代固定資料檔」用於主動換檔，不需要每次開啟與儲存都操作。
固定資料檔與下載備份 `minimajo-editor.json` 格式為 `{format:"minimajo-editor",version:1,schema,data}`，data 包含 characters（含 jobGrowth、raceBonuses、rarityBonuses）、skills、statuses、laws、enemies、map、capacity、config、echo。
下載備份以瀏覽器快取中的全部已儲存內容為準；即使固定檔案寫入失敗，也可以下載這些內容。不包含未儲存草稿、試打陣容或旅程進度。
主動匯入備份仍先逐欄補值、驗證全部資料與地圖生成／敵隊引用，顯示補值紀錄，確認後覆蓋固定檔案並重新載入；寫入失敗保留原檔及目前內容。完整備份不接受單庫 JSON，無法解析或辨識的檔案不會覆寫現有資料。失效引用／重疊格位補 null，空敵隊保留但停用抽選，無法生成的地圖規則回復預設並列出修復範圍。被選取的外部備份原檔不修改。

### 互換位置行動效果

效果編輯器新增「互換位置」，可用於角色行動、極式與法則效果資料。僅選同陣營存活單體，排除自身；沿用最近、隨機、最低血量、最高失衡與狀態篩選，屬性與戰鬥狀態條件統一放在各搜尋組的 targetCond，最多十二條，可選全部／任一成立，所有效果共用。互換最多一組同陣營單體搜尋，沒有數值／公式欄位。先依全部條件篩選，再以最近、最低血量、隨機等方式選取。
先排除無法交換的候選人，再依選取方式挑一人。交換雙方起始格，寬度不變；不能超界、互相重疊或占到第三名活隊友，無合法目標就略過。只互換站位，不交換陣營、血量、狀態、冷卻、角色身分或統計，也不另外增加行動次數。互換作為主效果時找到合法對象即執行，無對象則走移動分支；作為副效果失敗只略過自己。交換立即改變位置，後續效果按新位置搜尋。
法則新增 `swapInitiated`（自身主動互換位置時）與 `swapReceived`（自身被互換位置時），事件角色固定為自身。這兩種戰鬥時機已執行觸發；交換雙方也各發送一次移動事件。「互換位置時」（swapped）在每次成功互換後只發送一次，事件角色為發起互換的角色，位置以互換完成後為準。可用敵方範圍監聽敵人互換，仍受同一事件鏈每條被動最多發動一次的限制。普通移動、跳躍及失敗的互換不觸發。

### 跳躍與射程

新增 jump「跳到敵人對面空格」，無數值／公式，預設敵方最近單體／不限距離。最多一組敵方單體搜尋，先檢查落點再排名；落點為我方與敵人起始格同欄，完整佔位不得超界或占到其他活隊友，已在對面（佔位重疊）時視為就位並接續效果。可跨越隊友、不受普通移動距離限制；成功後副效果依新位置執行，失敗沿用主副效果分支。死亡隊友釋放格位但仍保留統計。「落點被佔用時」預設不換位，可開啟換位備援。隊友須從落點格開始佔位，互換後雙方完整佔位均須合法。搜尋只排名可就位的敵人。原地就位不發送移動或互換事件，實際換位沿用互換事件。

角色行動、極式與法則被動的最近單體（含我方搜尋）統一使用施放角色 attackRange；舊搜尋 limited／unlimited 不再改變此規則。效果編輯器移除個別射程數字與距離政策。「正對面」新增為敵方單體選取，只找佔位區間重疊者，套用目標條件，沒有目標不回退。普通移動、互換及跳躍維持不受攻擊距離限制的位置搜尋。法則非戰鬥時機已移除。

### 加快角色行動與極式冷卻

效果「直接加快主動技能時間 N 秒」（advanceSkill）提前目標所屬陣營的主動技能就緒時間。秒數預設 1，範圍 0～10000，允許一位小數。預設以自身搜尋加快我方技能，同一項作用即使選中多人，每個陣營只加快一次。最多推至當下就緒，超出不保留，仍需玩家施放。沒有可用技能或本場關閉主動技能時略過，作為主效果未成功時沿用既有失敗流程。角色行動、主動技能與被動皆可設定，按作用順序執行。

作用種類 `advance`「直接加快時間 N 秒」直接提前目標 nextAction，預設 1 秒，允許 0～10000、最多一位小數；最多提前至當下就緒，超出不保留。最早下個 0.1 秒更新行動，每次更新最多一次；不改原始行動間隔、極式冷卻或戰鬥時間，僵直仍阻擋行動。角色、極式、法則共用，不套攻擊力或輸出加成，遵守同組條件與目標、作用順序。

### 主副效果與多項作用

編輯器明示一個主效果與零至七個副效果，可設為主效果、上下調整順序。為避免成長與既有快照產生雙份效果資料，底層保留有序 effects 陣列（首項 main，其餘 other）。舊空陣列仍保留為無作用行動。最近單體統一使用施放角色攻擊距離；極式也適用。每個效果組使用 cond／condMode、targets、actions；作用內容 actions 支援 1～8 項，可新增、刪除、排序，共用一次條件判斷與目標搜尋。依作用順序逐一對已選目標結算，後續公式讀取更新值，不重判條件、不補選目標；死亡目標略過，施放者死亡或僵直中止。互換與跳躍不可放在同組。各搜尋組含 side／mode／targetCond／targetCondMode（range 僅保留舊格式相容），目標屬性、戰鬥狀態及 HP 等數值條件整合在同區。空條件不限制；空 targets 代表沒有目標；同效果各組合併去重。施放者或符合條件角色數量可作為發動條件。公式為 0、滿血治療仍屬成功執行。

角色 movement 預設朝敵方最近者移動，可改我方及條件，不受效果射程限制，排除自身並遵守原佔位路徑；移動後等待下一次行動。舊 targeting 編輯時轉為新欄位。「原主要敵人」選項、legacyEnemy 與效果 when 條件已移除；讀檔列出修復紀錄，需重新確認條件。不覆寫原始存檔，新增欄位逐欄修復並保留 0、false、空陣列。

傷害、失衡、護盾、治療、狀態、交換均立即生效；持續狀態按附加順序及內部規則順序結算，致死後不再恢復。反擊只由存活受擊者觸發，反擊致死取消施放者其後效果。超時仍是對雙方的一次環境事件，可同時全滅。完整規則見 README「主副效果、條件與目標搜尋」。

### 目標基準、事件與額外作用

同伴目標搜尋新增 allLeft／allRight（自身左／右側全體）及 leftmost／rightmost（符合條件者中最左／右一人）。左右全體只選其他同陣營角色。最左／右單體可選我方或敵方，搜尋所選陣營整排符合條件的存活角色。我方仍排除自身，四種搜尋都先套目標條件且不限距離。左右按完整佔位邊緣判斷，允許跨空格。最左／右搜尋整排符合者，不限於施放者某一側。多格角色只作用一次，換位後依新站位重新搜尋。互換可用最左／右單體，左右全體不可用於互換。

- targets 的 base 可為 actor（預設）、main（主效果實際選中的角色）或 event（觸發被動的事件角色），excludeSelf 可排除施放者。相對選取支援本身、左鄰、右鄰、左右鄰居、本身加鄰居。主效果及事件定位保留當時完整佔位，多基準合併去重，空格不跨越，死亡者本身略過但可找原佔位鄰居。
- 最近單體在角色射程內，同距離隨機。多格角色按整段佔位計距，佔位重疊即距離 1。正對面同距離取左側，沒有目標便略過。
- 共十九種被動時機，完整 ID 與事件角色見 README「戰鬥法則被動」。normalHit 事件角色是攻擊者，normalDown／normalKill 只通知直接造成結果者，事件角色為敵人。statusGained 每次施加、刷新與永續累加均觸發，可篩狀態正負分類或指定 ID。swapped 每次成功互換一筆，以發起者為事件角色。playerSkill 是結算前雙方全域事件，allySkillResolved 是結算後同陣營事件。
- 固有被動與每份法則的每條被動在同一事件鏈最多發動一次，仍保留死亡／僵直及連鎖中止規則。
- cleanse 每目標移除一個負面狀態，依最近施加時間最早者優先，同時則依狀態順序，刷新會更新順序。無負面狀態仍可接續後續作用。
- advance 提前角色行動進度，advanceSkill 提前目標陣營極式冷卻，同項作用選多人時每陣營只計一次。兩者都最多推至當下就緒，秒數範圍 0～10000、可含一位小數。極式依然由玩家手動施放。

### 行動效果總覽

編輯器新增頂層「行動效果總覽」，`js/action-overview.js` 在 app 初始化後、tabs 前載入，以 `CharacterLibrary.getItems()` 取得已儲存設定，逐條使用 `EffectEditor.describe` 產生主／副效果說明，並列出角色被動的觸發時機、事件角色範圍、全部符合條件與被動主／副效果。無被動或無發動效果時明示；玩家極式事件明示雙方持有者皆可觸發、不檢查事件角色範圍與屬性。名稱搜尋（忽略大小寫／兩端空白）、種族／戰鬥類型／職業／階級下拉篩選取交集，預設全部，支援重設、筆數與空結果。所有文字透過 textContent 建立；只讀、不保存篩選，不顯示角色草稿或手寫 description。角色與狀態儲存事件及切回此頁時更新。無新增資料欄位或改變戰鬥規則。`tests/browser/action-overview.cjs` 已以隔離 Edge／暫存 JSON 驗證自動說明一致、主副效果、空效果、單一／組合篩選、名稱／階級／重設／空結果、草稿隔離、儲存更新、唯讀瀏覽及 1440px／390px 版面與重載；未改寫正式 JSON。
