# UI 美術方向與目前實作

現況整理：2026-11-08。操作規則見 [UI_DESIGN](UI_DESIGN.md)，角色繪圖見 [ART_STYLE](ART_STYLE.md)，正式素材位置見 [素材索引](../assets/README.md)。歷史示意圖與試看網頁已依使用者要求清理，現有正式頁面和素材是目前採用版本。

## 整體方向

- 羊皮紙、低彩度藍墨、古老童話與版畫感；背景維持神秘暗黑與抽象魔法。
- UI 不必套用角色頭像畫法。細曲線、固定端飾與清楚的大輪廓優先，避免過密小裝飾、過亮藍底與大面積紫黑。
- 標題牌置中並半超出紙框；按鈕、紙面與角色卡由各自元件組合，不使用包含文字／角色的整張概念圖代替實際 UI。
- 三片式按鈕與出售區的圖層交接保留3px內部重疊，避免固定畫布縮放至小數像素時露出深色接縫；端飾與文字仍沿用既有素材。
- 法則選項九片底板在內側交接重疊3px；紙面彈窗於九片框內側補底色，保留外角透明輪廓。遊戲內容捲軸共用12px細線軌道、固定尺寸端飾與中央三點握柄（CSS／內嵌SVG），只延展深藍中段，由css/ui-scrollbars.css管理；商店介紹內容右側預留10px，涵蓋角色詳情、商店介紹、法則文字、極式與領獎長文區。
- 正式遊戲以1600×900橫版畫布作為UI尺寸與定位基準，外層整體等比縮放，直向旋轉90度、其他空間留黑邊；彈窗與戰鬥iframe共用此基準，不按手機寬度另排。工坊保持原網頁版面。
- 地圖地板沿用原PNG，以SVG三角網格投影並裁切在六角格內；格線、材質與相機共用座標，不使用foreignObject中的CSS 3D材質圖層。
- 概念圖的數值與文字不是遊戲規則，實際設定與共用控制器才是依據。

## 角色卡與隊伍

- 使用 v3 四職業三階邊框及配套遮罩；支援職業沿用已採用的新版頂弧／直側邊成品。卡寬由佔格決定，不依職業或階級決定。
- 正式隊伍十格、零格距，單格基準134×288，兩格268×288、三格402×288；石板可放區1340×288，基準包覆區1404×352。戰利品卡有自己的間距與幾何，不直接套隊伍底板。
- 角色維持頭至胸部的細長圖片槽；詳情使用專用4:5圖片，不拉伸卡圖替代。沒有圖片時保留預留槽。
- 星等放於既有框內安全區，資訊圖示維持小尺寸可辨。種族／屬性紙米黃，血量灰玫瑰銅、攻擊力與攻擊距離灰藍。

## 戰鬥

- 採現行裂白背景與薄角十格石板，控制元件使用獨立標牌、圓框、紙框與書本。冷卻、文字與極式圖案獨立呈現。
- 菁英／BOSS 敵方標牌右側分隔線區有54px技能圓框，使用既有圓框及技能圖案，可查看說明；一般敵方不顯示。
- 敵方上方為倒數與開始／暫停；我方下方為極式及速度、整備等控制，依可用空間調整位置。
- HP與護盾沿用共用量條，失衡另列；狀態圖示從名字上方排起，依可用空間換行與縮小，不跨鄰卡或被肖像遮罩裁掉。
- 狀態圖片只依狀態imagePath；極式圖片只依技能imagePath。空白／缺圖採既有通用符號。極式使用已選剪紙疊影圖案，保留疊層與每款一至兩色系。
- 動效遵守暫停、倍速及減少動態效果設定，勝敗確認沿用現行覆層，不因改圖修改結算時機。

## 整備、商店與獎勵

- 整備採既有紙面、深色出售長框與左短／右長標題分隔線；端點與中央尖芒固定，只延展線段。尖芒以整排隊伍中心為基準。
- 商店沿用已採用的古老魔法壁面、獨立紙面、固定端點按鈕與水晶；角色分頁三排同時顯示，法則分頁保留兩隊。商店不提供主動技能裝備。
- 法則卡與戰利品卡各自維持既有結構，不照搬戰鬥卡。詳情使用專用肖像框、姓名牌、分區標題與分隔線。
- 法則圖案已採B風格抽象符文：平面深藍黑主線、少量灰藍點綴、尖角與彎鉤，避免明顯材質感。32枚256×256透明PNG位於assets/ui/law-icons/v1/，使用01-law.png～32-law.png，圖形最長邊208px並保留留白；固定法則imagePath已指定，商店沿用既有圖片槽。
- 整備與戰鬥角色詳情的法則列表以32px圖示及名稱為首行，下方縮排顯示「－」效果說明；多行敘述各自列出，保留重複法則與既有分隔線，長文沿用右側整區捲動。
- 戰利品彈窗依選項總寬收合，窄版換行；選取碎晶約一半重疊卡頂。介紹區預留固定高度，長文於內部捲動。
- 技能選擇沿用v4紙實底、雙層黑邊選項與已採用PNG捲軸；選項圖示增加左側留白並使用深藍灰圓底，內距隨視窗縮放；點選看說明，確認才裝備，取消不提交。

## 維護與確認

正式素材在 assets/，必要切圖／校準來源在 [UI製作資料](ui-style/README.md)。三張角色畫風參考仍在 docs/art-style/，網路角色參考已刪除。

新圖先放暫時工作區，候選→使用者確認→正式套用。確認前僅在隔離測試載入，不影響正式頁；確認後同步更新引用與素材清單，整理未採用版本，保留必要來源與提示。後續測試在正式頁建立記憶體情境，輸出到 tmp/，不恢復獨立試看網站或永久累積示意圖。

搬移素材需同步修正CSS相對路徑、JS動態遮罩與資料欄位；動態CSS圖片以document.baseURI解析完整網址。替換卡框遮罩或能力圖示後重新產生file://內嵌資料。
