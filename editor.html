結算規則
全部角色死亡則落敗；同時全滅則平手。攻擊距離＝1＋雙方佔位區間的最短格差，優先正對面，再選射程內最近存活敵人（同距離隨機）。沒有射程內目標時，消耗一次行動朝敵方移動，不穿越隊友。極式由最左方存活角色施放；治療與護盾作用於施放者。護盾吸收傷害，但命中護盾仍會累積失衡。每次攻擊增加基礎傷害一半的失衡（向上取整），從 0 累積至 100 後倒地 4 秒，後續傷害 ×1.5；結束後失衡歸零。倒地時仍可攻擊與施放，但不能降低失衡，也不延長倒地時間。「僅敵方倒地時」依該批效果開始時判定，造成倒地的同批效果不會觸發追擊。極式開場就緒，冷卻依極式設定。超時依 Config 設定對雙方施加每秒遞增穿盾傷害。
    

    

    

    極式工坊
    

    正式旅程由玩家從全部符合條件的極式中選擇；工坊試打以清單中第一個符合項目為預設。沒有符合極式時無法施放。
    

    使用專案內相對圖片路徑；尚未有素材時留空，戰鬥按鈕保留預設圖案。
    

    出現條件
    隊伍數量先篩選角色再計數，可組合「人類、SSR／UR、3 星以上」，再比較人數 > 3；同一角色只計一次。站位 1 → 10 由左到右，空槽不遞補。無條件表示任何非空隊伍皆符合。「排在之前」只需存在一對符合者，不限相鄰。
    

    主效果與副效果
    極式不受射程限制，仍依條件搜尋存活目標。主效果成功才接續副效果；完全沒有符合條件的主目標時消耗冷卻，但不移動。

    一般狀態同名覆蓋數值並刷新時間；強化狀態永久累加。閃避固定 1 次敵方普通攻擊。施加量由技能提供；此處定義狀態如何作用。公式以狀態持有者為 self／target／enemy，時間目前以 0 計算。

    圖案使用專案內相對路徑；尚未有素材時留空，商店保留圖案位置。
    售價 0 表示免費；權重 0 完全排除商店抽選。
    永久屬性增減
    0 表示不改變；負值可縮短冷卻或倒地時間。加成在角色裝上法則後生效。
    被動觸發規則
    依序設定「何時 → 哪些角色符合條件 → 發動哪些效果」。被動於戰鬥事件觸發，與角色被動共用條件與效果規則。
    職業成長與種族／階級加成
    固定數值增減；秒數以 0.1 為單位，其餘為整數。負值可縮短冷卻／自身倒地時間；失衡效果值調整行動中的失衡效果。儲存會一併保存六個分頁的設定。
    守護升星成長
    每列為升到該星級時的固定增減量，從角色起始星數之後累加；起始星數不套職業成長。
    破陣升星成長
    每列為升到該星級時的固定增減量，從角色起始星數之後累加；起始星數不套職業成長。
    飛襲升星成長
    每列為升到該星級時的固定增減量，從角色起始星數之後累加；起始星數不套職業成長。
    支援升星成長
    每列為升到該星級時的固定增減量，從角色起始星數之後累加；起始星數不套職業成長。
    種族加成
    依角色的種族套用一次固定數值增減，所有星等均適用，不隨升星重複累加。0 表示不改變。
    階級加成
    依角色的階級套用一次固定數值增減，所有星等均適用，不隨升星重複累加。0 表示不改變。
    快速隨機生成
    每次建立一支全新隊伍，保留既有隊伍。首次命中使用起始星數，重複命中直接升一星（最高六星），僅用於此工具。放不下或已六星的角色排除再抽；無合法候選時提前停止。階級內角色及法則沿用各自出現權重，0 不抽選。每份法則等機率附加至一名角色，可重複堆疊。
    新隊伍預設一般、適配等級 1、出現權重 100，可在下方調整後儲存。抽選參數僅在本頁使用，重載回復預設。
    敵方隊伍
    編輯敵方隊伍
    一般與菁英先選最接近隱藏玩家等級的隊伍（同距離取較低等級），再依該等級權重抽選。BOSS 僅依權重、不適配等級；權重 0 不出現。同一節點重試保持同一敵隊。陣容引用角色名冊的能力，不受商店權重影響。
    每隊十格。角色佔 2～3 格時，後續被佔用格請保持空位；可重複使用同一角色。
