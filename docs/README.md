# MiniMajo 角色與隊伍工坊

接手開發請先讀 [AGENTS.md](../AGENTS.md) 與 [專案現況與交接](PROJECT_CONTEXT.md)，養成與經濟的完整規則見 [局內成長與經濟規格](PROGRESSION_SPEC.md)。交接文件整理架構、資料格式及限制；本文件提供操作與戰鬥規則。

本文的原始碼路徑、頁面與指令皆以專案根目錄為準。

啟動編輯器：雙擊專案的 `啟動MiniMajo.cmd` 會自動開啟正確的瀏覽器網址；同專案服務已啟動時直接沿用，不重複占用連接埠。首次啟動的服務視窗請保持開啟。也可執行 `node editor-server.cjs` 後手動開啟 `http://127.0.0.1:4173/editor.html`。固定資料檔為根目錄 `minimajo-editor.json`，開啟自動載入、各分頁儲存自動覆蓋；以頂部「已同步」確認寫入完成。

角色繪圖的已定案畫風、參考圖與可重用提示詞見 [角色繪圖風格規格](ART_STYLE.md)。來源素材位於 `docs/art-style/references/characters/`；重繪必須另行設計與素材不同的新姿勢，候選圖、來源副本與提示詞保存於 `docs/art-style/candidates/`，經確認後才套用。既有方形胸像僅作畫風參考；後續卡圖必須依已確認的 1／2／3 格卡片比例製作，佔格不明時先詢問使用者再生成。人體範圍統一為頭至胸部，不因窄幅畫布改畫腰腹或腿。卡框上緣弧度與裝飾會遮圖，臉部不得比已套用的青青更高，須預留遮擋安全區並套目標框檢查。青青與友萌已確認套用，固定資料的 imageFile 分別為 `qingqing-1slot.png`、`youmeng-1slot.png`；友萌採第 4 方向的手部／排線修正版，已檢查飛襲 SR 框未遮五官；新旅程載入，已開始旅程不即時換圖。

正式角色與 UI 圖在 assets/；三張定案畫風參考在 docs/art-style/。網路角色參考、歷史候選、UI 比較頁及一次性截圖已清理，必要切圖／校準來源在 docs/ui-style/sources/，詳見 [素材索引](../assets/README.md)。

## 固定分類與角色屬性

每名角色的完整美術素材為兩張：依 1／2／3 格比例製作的卡圖，以及不隨佔格改變的 4:5 詳情頭像（建議 800×1000；介面依螢幕縮放）。兩張分別指定 `imageFile` 與 `detailImageFile`，詳情回退卡圖只作缺素材備援。友萌已套用一格卡圖 `youmeng-1slot.png` 與專用詳情頭像 `youmeng-detail.png`（減雜點、v3 手部修正第二張）；製作規範見 ART_STYLE.md。

角色的「圖片檔名」填入例如 `moon-witch.png`，將素材放在專案的 `assets/characters/` 資料夾，不需填路徑。欄位預設留空，最多 120 字元，支援 PNG、JPG／JPEG、WebP、GIF、AVIF、SVG；不接受網址或子資料夾。角色名冊、整備／商店、戰後三選一與戰鬥共用這個設定；戰鬥卡等比例裁切滿版，其他圖片槽保留原比例完整顯示。角色基本屬性另提供「詳情圖片檔名」（detailImageFile），預設空字串，同樣從 assets/characters/ 讀取且沿用相同檔名驗證；建議提供 4:5、800×1000 的固定詳情圖。整備／戰鬥詳情優先顯示專用圖，留空或缺圖時退回角色卡圖，兩者都缺圖才保留預留槽。專用圖不改變隊伍卡的圖片。未指定或讀不到卡圖時保留預留槽；正式素材的採用狀態見 UI_ART_DIRECTION.md。舊版 emoji「圖示」讀取時改為空白圖片檔名，列入補值紀錄，其他設定保留，原始存檔不會自動覆寫。圖片檔案本身不包含在 JSON 備份內，換裝置時需另行複製。

分類由 `js/enums.js` 定義，沒有自訂標籤管理器：

- 種族：人類／獸人／機人。
- 戰鬥類型：物理／精神／魔法。
- 星等：1～6 星。角色資料存初始星等；試煉場槽位可從初始星等調至 6 星，不改寫角色資料。調整會重置戰鬥，並重新判定極式。
- 階級：SR／SSR／UR。固定角色資料，不因本局星等改變。
- 職業：守護／破陣／飛襲／支援。
- 佔用空間：1～99，目前每方十格；多格角色連續佔位。工坊空間上限預設 10，可調整為 1～10。重疊、超出格位或空間上限時禁止開戰。

頂層「行動效果總覽」可一覽已儲存的全部角色行動效果，與各星級能力預覽共用自動說明（不是手寫技能說明），主／副效果分列，並顯示角色被動的觸發時機、事件角色範圍與全部符合條件，以及各被動的主／副效果自動敘述；沒有被動或發動效果時明示。玩家極式事件標示其不檢查角色範圍與屬性的規則。可搜尋角色名稱，並以種族、戰鬥類型、職業及階級篩選；不同條件取交集，預設全部，可按「重設篩選」還原。顯示符合／總筆數，無結果時明示。角色儲存、新增或刪除後更新；未儲存草稿不顯示，篩選僅影響此總覽，不寫入資料檔。

### 成長與狀態加成

「成長與加成」有守護、破陣、飛襲、支援、種族、階級六個分頁，共用下列十一欄。職業只設升至 2～6 星的五列增量，從角色起始星數之後累加。種族與階級各套用一次，法則永久屬性按持有份數相加。各欄預設 0，編輯範圍 -10000～10000。

| 欄位 | 資料鍵 | 單位及用途 |
|---|---|---|
| HP | maxHp | 整數，調整最大血量 |
| 傷害／治療／護盾攻擊力 | damage／heal／shield | 整數，分別加到對應攻擊力後再乘技能倍率 |
| 冷卻秒數 | cooldown | 0.1 秒，調整普通行動間隔 |
| 失衡效果值 | posture | 整數，增加失衡結算時最後相加 |
| 倒地秒數 | weakDuration | 0.1 秒，調整自身倒地時間 |
| 移動距離 | moveDistance | 整數，調整普通移動上限 |
| 攻擊距離 | range | 整數，調整最近單體搜尋的射程 |
| 狀態秒數加成 | statusDurationBonus | 0.1 秒，施加秒數型狀態時加到持續時間 |
| 狀態層數加成 | statusAmountBonus | 整數，狀態施加量算完後相加 |

能力套用後限制為 HP 1～10000、冷卻／倒地 0.1～120 秒、移動 0～9、射程 1～10。成長預覽、工坊試打、敵隊、旅程及合成都走相同計算，旅程從角色快照重建，避免升星與裝法則重複計入。各分頁保留草稿並統一儲存，新設定在下一局旅程載入。

狀態施加量先算公式，再加 statusAmountBonus，限制 0～10000。狀態秒數先按狀態規則正規化，再加 statusDurationBonus，限制 1～999 秒並取小數一位。行動次數、永久、攻擊次數不加秒數。閃避、嘲諷及其他不使用施加量的固定規則狀態不加層數。普通行動、角色／法則被動與極式都取實際施放者的這兩項加成。例如 HP 10、施加量 self.hp*2、10 秒，搭配層數 +3、秒數 +2，結果為 23 點、12 秒。

「層數加成」調整技能的施加量數值，同名狀態仍是一份狀態，永續狀態則累加施加量。

角色詳情的狀態秒數／層數加成顯示有正負號的總值，秒數另標「秒」，零值亦列出。欄位提示說明它們分別加到技能的持續秒數與施加量。

兩項狀態加成以角色的 statusDurationBonus／statusAmountBonus 傳入戰鬥，三類攻擊力及失衡加成保存在 outputBonuses。跨 iframe 的 ItemDB.runtime 會驗證並保留。缺少或無效的新欄位由 js/saved-data.js 逐欄補 0，合法 0 保留。

## 極式

每個技能可設定效果、CD（0.1～120 秒）與條件，不再設定或保存優先度。條件支援數量、指定站位、A 排在 B 之前，以及多數分類。可以依種族、戰鬥類型、星等、階級、職業或指定角色篩選；多數不適用角色 ID。

「隊伍數量」改為先設定角色篩選，再比較符合者人數。每組最多 12 條篩選，可選全部／任一符合；分類支援等於、不等於、符合任一所選值及排除所選值，星等支援 =、≠、>、≥、<、≤（1～6 星）。人數也支援六種比較（0～10）；多格角色只計一次，空格不計，空篩選計全部角色。例如同一組設「種族＝人類」「階級符合任一所選值＝SSR、UR」「星等≥3」，角色篩選組合選全部符合，再設人數 >3，就需要至少四名同時符合的角色。

數量條件新增格式 `{kind:"count",filters:[{field,op,value}],filterMode:"all",op:"gt",count:3}`；多選使用 `op:"in"`／`"notIn"` 與字串陣列，星等值使用整數。filterMode 預設 all；合法空 filters 保留，count 0 保留；讀檔時無效欄位逐項補預設並列出紀錄，不丟棄整個技能。舊單屬性數量、站位、排序及多數條件照常讀取，數量條件於編輯儲存時改存新格式，原檔不因單純讀取而改寫。

條件可全部成立或任一成立。無條件對非空隊伍成立。正式旅程在整備選單列出全部符合條件的技能，由玩家自行裝備；新旅程不自動裝備，失效後也不自動換成其他技能。工坊試打／獨立展示保留以資料庫順序的第一個符合技能作為展示預設，不參與正式旅程的選擇。條件編輯器顯示目前隊伍的符合結果。空隊伍或無符合技能無法施放。

極式每場從 0% 充能，經過完整技能 CD 才可首次施放，暫停不推進。極式僅我方具備，由玩家手動施放；工坊、獨立展示與正式旅程的敵方均無極式。敵方角色自身行動效果照常執行。

## 效果與公式

每名角色行動、被動或極式有一個主效果及最多七個副效果，依序存於 effects。每組使用 cond、targets、actions，最多八項作用共用同一次條件判斷及目標搜尋。主副效果與目標規則見下方「主副效果、條件與目標搜尋」。

| 作用 | type | 設定 |
|---|---|---|
| 傷害、治療、護盾 | damage／heal／shield | 對應攻擊力倍率加公式與常數 |
| 增加／降低失衡 | posture／restore | 基礎攻擊力倍率加公式與常數 |
| 加快角色行動 | advance | 提前目標 nextAction N 秒 |
| 加快主動技能 | advanceSkill | 提前目標陣營的極式就緒時間 N 秒 |
| 施加狀態 | status | 狀態 ID、施加量與持續方式 |
| 解除負面狀態 | cleanse | 每名目標解除一個負面狀態 |
| 互換、跳躍 | swap／jump | 位置搜尋，跳躍可設 swapFallback |

角色普通行動與固有被動可設固定或隨機攻擊倍率。傷害、治療、護盾各用自己的攻擊力，公式為「對應攻擊力 × 倍率 ＋ 數值公式 ＋ 常數整數」。對應攻擊力取基礎 attack、同類 outputBonuses 及同類狀態增減的合計，最低 0。傷害使用 power／weakness，治療使用 healing／healingWeakness，護盾使用 hard／fragile。角色固有被動沿用相同數值計算，反擊、閃避與普通攻擊命中事件仍依各自的觸發規則判定。

增加／降低失衡的倍率項使用基礎 attack。增加失衡再於最後加上 outputBonuses.posture，降低失衡不加此值。極式與法則被動只設定公式及常數整數，倍率項不取施放者攻擊力，但公式仍可明確引用角色戰鬥數值。

amount 可為整數常數或 {multiplier,formula,constant}。倍率預設 0、可填 0～100 或 {min,max}，每目標獨立抽取。formula 預設 "0"，constant 預設 0、範圍 -10000～10000。效果量加總後四捨五入，限制 0～10000，傷害另依受擊者當下倒地狀態套承傷倍率。狀態施加量使用常數、隨機整數或公式，其後再套「狀態層數加成」。

| 公式參照 | 意義 |
|---|---|
| self.* | 施放者，固有被動取持有者 |
| target.* | 此項作用正在結算的實際受作用者，群體效果逐人取值 |
| enemy.* | 對敵方作用時取該敵人，對我方作用時取本次行動參照的主要敵人 |
| *.attack | 基礎攻擊力，與倍率計算的加成後傷害／治療／護盾攻擊力分開 |

另可取 hp、maxHp、missingHp、shield、posture 及戰鬥 time。狀態庫內的規則公式，self／enemy／target 均指狀態持有者，time 固定 0。所有選單標籤與實際引用以 js/effects.js 的 refs 為準。

戰鬥卡「攻擊力」顯示目前傷害攻擊力。戰鬥詳情另列治療力、護盾力、失衡效果加成及兩項狀態加成，直接顯示總值。星級、種族、階級、法則與當前狀態都按該類規則計入。行動間隔顯示成長／法則後的基礎間隔，急速、倦怠與僵直反映在實際行動進度。

共用角色詳情的狀態秒數加成採沙漏＋右下上升箭頭，狀態層數加成採三層堆疊＋右下上升箭頭。兩枚深藍透明 PNG 與原有能力圖示同為 22px，戰鬥、整備及商店介紹共用；數值與計算方式不變。

狀態本身的15種基本圖案與7種永續∞版本已正式接入戰鬥卡與戰鬥詳情，22枚透明PNG位於assets/ui/status-icons/v1/，見 狀態切圖與套用。深色襯底由UI另外提供，六組配色只作視覺分組，不更動正負面規則。卡片狀態列對齊名字列的內側左右邊界，滿行向上換行，暫停時縮放視窗也重新計算；狀態多或低高度時自動縮小徽記；狀態獨立於肖像遮罩，避免多排時被卡框裁掉。詳情保留完整狀態名稱、數值、秒數／次數／永久及原有能力欄位。圖片完全由狀態imagePath決定，空白或載入失敗只顯示通用符號，不依ID挑選圖片。22筆定案圖路徑已透過editor-server寫入固定JSON；可以直接在狀態編輯器查看、替換或清空。

速率按鈕旁的「手動／自動」切換控制我方極式，預設手動；自動模式在極式就緒且符合原有施放條件時自動釋放，開戰前、暫停、隱藏頁面、施放者僵直、極式關閉／未裝備或戰鬥結束時不會施放。戰鬥中切到自動且極式已就緒會立即施放；切回手動停止後續自動施放，仍可直接點極式施放。同一戰鬥頁內重新試煉及整備刷新保留模式，重新載入頁面回到手動，不寫入固定 JSON 或進度存檔。敵方仍不施放隊伍極式。控制列靠齊隊伍石板右緣，整備隱藏後仍維持同一右側基準；較窄石板下的長控制列下移避開極式，1000px 以下移至極式下方。

戰鬥卡動效：直接傷害攻擊時整卡朝對方短彈（我方向上、敵方向下，約 0.3 秒），實際受傷或護盾吸收時左右短震（約 0.24 秒）；閃避只播放攻擊彈動，不播放受擊震動。角色／法則被動觸發時，持有者播放約 0.62 秒的淡金光暈擴散淡出。同一畫面更新內的同類觸發合併，攻擊與受擊可同時播放。失衡倒地覆暗暖濾鏡，僵直覆冷灰斜紋，恢復後自動移除；資訊列仍保持可讀，死亡角色依原規則退場，統計不顯示濾鏡或動效。暫停凍結動效，2 倍速同步加速；系統設定「減少動態效果」時停用位移與光暈。動效只讀戰鬥事件，不延後傷害或改變規則；獨立展示、工坊試打與旅程共用。

命中回饋第二版：HP 紅條立即更新，淡紙色缺血殘影以約 0.3 秒追上；連續受傷從當前殘影接續，補血追平時取消，護盾分母變化時重新換算比例。護盾吸收不產生缺血殘影。直接受擊加約 0.18 秒卡圖閃光，純護盾吸收偏冷藍，傷及 HP 偏暖色，同次畫面更新兼有兩者時使用暖色。失衡真正跨過倒地門檻時，整卡下沉 9px 後回彈、失衡圖示放大回復（約 0.36 秒），不因維持倒地重播；同時攻擊時優先播放倒地下沉，左右受擊震動仍可並行。三者均跟隨暫停與倍速，減少動態效果及統計模式取消動畫，死亡維持原有退場規則；未新增圖片或改變傷害／倒地規則。

支援及閃避回饋：實際治療量大於0時，在卡圖內由下往上掃柔綠光約320ms；新增護盾大於0時，外緣冷藍光圈擴散淡出約360ms。資訊列保持可讀，滿血溢補與0增量不播放。閃避浮出MISS約850ms，不側閃或改變格位；同次普通攻擊的後續效果仍被該次閃避阻擋，只浮一個MISS。極式冷卻完成且符合施放條件時圓框亮起、放大約6%後回彈（380ms），每次充能僅提示一次，不因暫停或僵直解除重播；自動模式若立即施放便直接進入既有施放效果，不另停留就緒提示。新回饋跟隨暫停及倍速，統計／重試清理；減少動態效果停用掃光、光圈與圓框動畫，MISS改為短暫靜態文字。數值、閃避及施放規則不變。

戰鬥音效：命中短促敲擊、純護盾吸收清脆短音、倒地低沉撞擊、被動輕鈴、成功施放極式的魔法爆發，以及超時扣血低頻脈衝。以 Web Audio 原生合成，預設開啟，需使用者首次操作後才建立／解鎖音訊；不支援或解鎖失敗時仍可正常戰鬥。右上「音效／靜音」切換，偏好獨立記錄於 minimajo.battleAudio.enabled，不屬於編輯器備份或旅程進度。暫停、背景分頁、查看詳情、統計及重試停止正在播放的聲音，不累積待播事件。群體命中依每次畫面更新合併，兼有血量與護盾命中時以血量音為主；短節流及聲部上限避免密集疊音。2倍速維持原音高，以實際事件頻率觸發。音效不受「減少動態效果」影響，可獨立靜音。逐項試聽。

音量於工坊「Config 設定 → 戰鬥音效 → 戰鬥音量（%）」調整，範圍0～100、預設60；0為無聲，與右上靜音偏好分開。此值屬編輯器Config及完整備份，按原設定快照規則於試打重設／下一次新旅程套用。缺少、型別錯誤或超界值逐欄補預設60，不因新欄位拒絕舊檔或正在傳入的舊戰鬥快照。音量增益位於壓縮器後，維持音量調整的明顯差異；整體輸出已提高。

死亡及位移：角色死亡後以不可點擊、不佔格的視覺殘影向下30px、約380ms淡出；真正的死亡、目標選擇、格位空出及結算均立即生效。跳躍約180ms快速滑移並略微拋起；互換雙方約140ms同時位移、走不同的短弧線，普通移動亦採短滑。同一更新內多段移動依原始起訖格依序播放，連續觸發從當前視覺位置銜接；多格角色保持原佔位寬度。同次移動後立刻死亡時，從最後可見位置淡出。暫停凍結、2倍速加快；統計／重試清理殘影，減少動態效果直接更新位置，縮放視窗時取消舊尺寸動畫以免偏位。

## 失衡與倒地

Config 的「倒地行動速度降低（%）」（downSlowPercent）預設 20，範圍 0～100 整數。倒地期間普通行動進度速度乘上 (1−降低比例)，急速／倦怠先計算後再乘倒地倍率。20 代表原速度的 80%，0 無減速，100 停止普通行動進度。僵直仍凍結進度，起身後恢復正常速度，極式冷卻不受此參數影響。舊檔缺少或無效值補20並列修復紀錄，合法0保留。

每位角色獨立 HP（預設 180）、護盾與失衡，失衡從 0 開始。預設命中（含護盾）增加基礎傷害一半的失衡，向上取整；滿 100 倒地，基礎持續時間由 Config 設定，預設 4 秒（職業成長與法則可調整自身倒地時間），後續傷害 ×1.5，倒地結束失衡歸零。倒地期間不能降低失衡或延長倒地，但沿用可自動攻擊／施放的原型規則。

倒地加成按每筆傷害發生前判定，造成倒地的那一擊不加成；其後的副效果已可搜尋倒地者並享受增傷。超過 Config 基礎時間後，雙方按 Config 扣血週期承受穿盾傷害，依設定間隔增加扣血量，直至分出勝負或同時全滅。暫停與背景分頁不推進戰鬥。

基礎時間歸零時，計時器轉暗紅並顯示 +00:00，畫面一次顯示約 1.5 秒的「侵蝕加劇」轉場及暗紅衝擊；之後保留低強度暗紅邊緣，每次實際超時扣血觸發 0.45 秒邊緣脈衝。視覺不延後或提前傷害，也不以紅色效果觸發受擊被動。轉場不攔截操作，暫停凍結、倍速同步加快；結果及統計移除覆層，重試可重新播放。減少動態效果時不播放縮放、衝擊或脈衝，改為 1.5 個戰鬥秒的靜態提示與持續邊緣色。文字先使用系統楷體與 CSS，尚未另外製作美術字。

效果名稱：posture／restore 分別代表增加／降低失衡；self.posture、enemy.posture 讀取目前失衡值。

## 儲存與完整備份

### 儲存相容與逐欄預設值

編輯器現在以專案根目錄 `minimajo-editor.json` 為固定來源。雙擊 `啟動MiniMajo.cmd` 會自動開啟瀏覽器，已有同專案服務時直接沿用；首次啟動服務的視窗請保持開啟。也可執行 `node editor-server.cjs` 後手動開啟 `http://127.0.0.1:4173/editor.html`；服務只綁定 127.0.0.1，不需安裝套件。可用 MINIMAJO_PORT 改連接埠，平常請保持位址不變。直接開 HTML 或使用一般靜態伺服器不能覆蓋固定檔案，編輯器會明確報錯並鎖定編輯。

修改資料驗證、效果或狀態等 JavaScript 程式後，必須先停止原有編輯器服務，再重新執行啟動指令，最後重新整理編輯器。Node 會保留啟動時載入的驗證模組；F5 只更新網頁，再次雙擊啟動指令也會沿用仍在執行的服務。新畫面搭配舊服務可能把新增的合法設定補回舊預設值，且仍顯示「已同步」。

開啟時先讀取固定檔案，完整補值與驗證成功後才同步到 localStorage 並啟動各編輯分頁；缺檔、JSON 無法解析或無法辨識的完整檔案會阻止載入，不使用空預設資料覆蓋檔案。單欄無效仍逐欄修復並列出紀錄，讀取本身不改寫固定 JSON。localStorage 是同來源頁面的資料快取，不是正式檔案來源；旅程進度仍只在記憶體。

各分頁原有儲存、新增／刪除等已儲存操作，以及地圖與空間上限的即時儲存，會自動將全部已儲存資料排隊覆蓋固定檔案；不包含未儲存草稿、試打陣容或旅程進度。頂部顯示「正在覆蓋」「已同步」或「寫入失敗」，請等到已同步再關閉。失敗保留瀏覽器中的已儲存內容並提供重試，尚未同步時離開會提醒；也可下載備份救回內容。檔案版本衝突需先下載當前資料備份再重新讀取，不會直接蓋掉其他分頁或外部修改。

本機服務只接受固定資料檔的讀寫，保存前驗證、以同資料夾暫存檔完整寫入並同步後替換；失敗保留原檔且清除暫存。每次覆蓋檢查載入時的內容雜湊版本，並將本機請求串行處理。這是編輯工具的本機檔案服務，沒有遊戲後端、帳號或旅程存檔。
`js/storage.js` 的 schema 僅為格式標記，不會因版本不同清除或拒絕資料。`js/saved-data.js` 統一處理讀檔：缺少、型別錯誤或超界欄位逐欄補合法預設，保留其他欄位、角色與資料庫；合法的 0、false、空陣列不會被覆蓋。
每個新增欄位必須同步定義讀取預設值與相容測試。HP、時間、名稱等使用合法預設；角色庫完全空白時建立一筆空白角色供編輯。單庫讀取與預覽不改寫來源；編輯器啟動時則依固定檔案重建瀏覽器快取，表單儲存仍嚴格驗證。工坊頂部提供補值紀錄，不提供手動清空資料按鈕。

### 匯出與匯入

頂部保留共用工具列：「下載全部編輯資料備份」提供額外備份；「以備份取代固定資料檔」用於主動換檔，不需要每次開啟與儲存都操作。
固定資料檔與下載備份 `minimajo-editor.json` 格式為 `{format:"minimajo-editor",version:1,schema,data}`，data 包含 characters（含 jobGrowth）、skills、statuses、laws、enemies、map、capacity、config、echo。
下載備份以瀏覽器快取中的全部已儲存內容為準；即使固定檔案寫入失敗，也可以下載這些內容。不包含未儲存草稿、試打陣容或旅程進度。
主動匯入備份仍先逐欄補值、驗證全部資料與地圖生成／敵隊引用，顯示補值紀錄，確認後覆蓋固定檔案並重新載入；寫入失敗保留原檔及目前內容。完整備份不接受單庫 JSON，無法解析或辨識的檔案不會覆寫現有資料。失效引用／重疊格位補 null，空敵隊保留但停用抽選，無法生成的地圖規則回復預設並列出修復範圍。被選取的外部備份原檔不修改。

## 角色獨立戰鬥與位置

獨立開啟 `battle.html`、工坊試打及正式旅程共用同一套戰鬥版面，沿用旅程的敵方上方置中倒數及大型開始／暫停按鈕、我方下方置中技能與右側速度／整備，以及簡化角色槽，不再分模式套用不同外觀。內嵌時隱藏頁首導覽；示範與工坊保留重新試煉，旅程由父頁管理戰鬥結果及獎勵。戰鬥頁不顯示紀錄，工坊父頁仍保留試打紀錄。各模式的隊伍、技能資料來源維持各自用途。

- 角色基本屬性：maxHp（1～10000，預設 180）、attack（0～10000，預設 10）、attackRange（1～10，預設 1）、moveDistance（0～2，預設 1）。舊資料缺少攻擊力補 10，攻擊距離取原效果最大合法 range（無則 1），列出補值紀錄且不覆寫原存檔。效果編輯器不再設各效果射程。
- 每位出戰角色分別保存 HP、護盾、失衡、倒地截止時間與下次行動時間。死亡不再行動、不可被治療復活，也不再參與極式組成。全部角色死亡即落敗，同時全滅為平手；空隊伍視為全滅。超時依 Config 對雙方施加依設定週期與成長量結算的穿盾傷害。
- 雙方佔位區間重疊視為正對面，距離為 1＋佔位區間最短格差。「最近單體」只在施放角色 attackRange 內搜尋，同距離隨機；「正對面」只選佔位重疊的存活敵人，沒有時不改選其他欄。各 targets 組獨立搜尋，合併去重後供本效果組全部作用共用。
- 主效果條件不成立或沒有合法目標時，略過全部效果並嘗試移動。移動有獨立搜尋設定，可選我方／敵方、條件與排名，不受攻擊射程限制且排除自身；預設朝最近敵人移動。只能走不超過移動距離的連續空格，不穿越活隊友；死亡位置視為空格。選擇能縮短與選中對象距離的最佳位置，同距離隨機。無目標或無路徑也消耗行動；移動後不在同次施放。
- 同時到期角色依每個 tick 交替的隊伍順序、隊內站位依序完成行動（含移動）。先被擊殺或施加僵直者取消尚未執行的行動；行動次數只計真正開始的行動。普通攻擊不再採同批傷害結算。
- 未指定目標的非攻擊效果預設作用於施放角色。極式由最左側存活角色施放，最近單體同樣使用該角色攻擊距離；主效果無目標或條件失敗仍消耗 CD，不自動移動。死亡或移動後重新判定技能條件，已有 CD 保留。
- self.* 公式指施放者，enemy.* 指選中的敵方角色，target.* 指本次實際受作用角色；最大 HP 讀取角色實際值。發動條件不再提供「原主要敵人」；檢查倒地請使用目標條件或戰場符合條件人數。
- 試煉場上方為即時站位與角色血條，下方為開場編隊。開始戰鬥後鎖定編隊，重置後可編輯。

## 角色狀態

角色與極式的效果列表可選「施加角色狀態」。指定陣營、選取方式、條件、狀態、施加量與持續方式；最近單體使用施放角色攻擊距離。施加量支援常數、隨機整數或公式，施加當下計算一次；狀態規則可引用該量、使用固定值，或於作用時計算持有者數值公式。

以下為內建狀態的預設行為，可在「狀態」分頁修改或建立組合狀態。

| 狀態 | 預設行為 |
|---|---|
| 嘲諷 | 射程內且符合目標條件時，優先承受敵方普通單體行動，多人時選最近者，同距離隨機，正對面／全體／明確指定目標除外 |
| 閃避 | 固定迴避 1 次敵方普通冷卻攻擊，不疊層；暫定整次行動對該目標的敵對作用（傷害、失衡、附加狀態等）全部略過，不產生受擊／反擊／激怒；反擊、被動、極式與持續傷害不消耗也不受閃避影響 |
| 永續中毒／永續再生／永續強化／永續虛弱／永續堅硬／永續脆弱 X | 與各原版效果相同；施加量由技能提供，固定永久至本場結束；同 ID 的 X 相加，不覆蓋；各自與原版並存 |
| 中毒 X | 每秒扣 X HP，無視護盾，不觸發反擊，不受強化／倒地放大 |
| 再生 X | 每秒恢復 X HP，上限為角色最大 HP |
| 混亂 X | 每秒增加 X 失衡，滿值觸發倒地；既有倒地不延長 |
| 鎮靜 X | 每秒降低 X 失衡，最低 0 |
| 激怒 | 受到敵方直接傷害時行動進度 +1 秒；含技能與護盾承傷，不含中毒與反擊 |
| 反擊 X | 受到敵方自動行動的直接傷害效果時，對來源造成 X 傷害；命中護盾也觸發 |
| 僵直 | 無法行動，行動進度凍結；該角色作為極式施放者時也不能施放 |
| 強化／虛弱 X | 傷害攻擊力分別加／減 X，先加總再乘技能倍率，最低為 0；常數項不變 |
| 堅硬／脆弱 X | 護盾攻擊力分別加／減 X，先加總再乘技能倍率，最低為 0；常數項不變 |
| 急速／倦怠 | 行動速度 +50%／−50%，X 為持續秒數；兩者並存抵銷 |

永續狀態持續本場戰鬥，一般狀態可選秒數或行動次數。秒數型為 1～999 秒（0.1 秒單位）；行動型為 1～999 次，按受影響角色自己的自動行動扣次數（移動與無法移動的等待同樣消耗行動，手動極式不扣）。新施加的狀態不扣當次行動，同名刷新後也不被舊狀態扣次數。急速／倦怠依本版規格只使用秒數。

N 次行動的僵直特例：以角色原始 CD 計算 N 次被跳過的行動機會，進度依然凍結，避免永遠不能解除。永久僵直持續至戰鬥結束。

一般同名狀態覆蓋強度、刷新期限，不疊層；強化狀態永久且累加施加數值，與原版各自並存。閃避固定只迴避一次敵方普通攻擊，不疊層、不按時間或自身行動消耗。狀態編輯器選擇閃避作用時鎖定固定值 1，停用倍率與公式；技能施加時鎖定 1 次敵方普通攻擊。刷新保留每秒效果的原始跳動節奏。初次施加後一秒才第一次觸發，期限最後一秒包含最後一次跳動。持續效果按角色狀態陣列、狀態內作用規則順序立即結算，後續公式讀取更新後數值；致死後略過後續規則與恢復。死亡清除狀態，不復活；重置戰鬥清除全部狀態。

反擊只由進度完成的直接傷害效果觸發（每個傷害效果一次），不由中毒、反擊或隊伍手動技能觸發；反擊也會被護盾吸收，受到反擊者的倒地增傷，並使用反擊者的強化／虛弱。反擊不額外增加失衡。受擊者存活才立即反擊或推進進度；反擊致死會停止施放者尚未執行的後續效果。新施加僵直會取消尚未執行的行動。

角色卡顯示狀態、剩餘秒數／行動次數、行動進度。js/statuses.js 管理可編輯狀態庫、作用規則與持續時間。

## 十格模擬戰鬥與移動

## 主副效果、條件與目標搜尋

同伴目標搜尋新增 allLeft／allRight（自身左／右側全體）及 leftmost／rightmost（符合條件者中最左／右一人）。左右全體只選其他同陣營角色。最左／右單體可選我方或敵方，搜尋所選陣營整排符合條件的存活角色。我方仍排除自身，四種搜尋都先套目標條件且不限距離。左右按完整佔位邊緣判斷，允許跨空格。最左／右搜尋整排符合者，不限於施放者某一側。多格角色只作用一次，換位後依新站位重新搜尋。互換可用最左／右單體，左右全體不可用於互換。

每個角色行動／隊伍手動技能有一個主效果，成功對合法目標執行才依序執行副效果。公式為 0、治療滿血等仍視為成功；若不希望治療滿血角色，請加入「已受傷」目標條件。副效果找不到目標或條件不成立只略過自己，不移動、不阻擋其後副效果。

手動技能施放即進入冷卻；主效果的 `targets: []` 會導致沒有傷害且後續治療不執行，不能只靠敘述指定目標。固定資料的「基礎極式」已補為隨機敵人搜尋，傷害沿用 `self.hp*0.5`（施放者目前血量的一半）；最低血量同伴的治療採 `target.maxHp*0.2`（受治療者最大血量的 20%）。修改設定後需重新載入編輯器快取，並開始新旅程才會套用。

- 發動條件 cond：可檢查施放者、戰場符合條件的存活角色數量。可選全部／任一成立，空條件不限制。
- 目標搜尋 targets：最多八組，各自指定陣營、目標條件及選取方式。每組先篩選再排名，結果依角色實例去重，每項作用內容對同一目標只執行一次。空陣列代表沒有目標，不能回填成預設搜尋。
- 目標條件 targetCond：種族、類型、職業、階級、星數、HP、HP 百分比、護盾、失衡、受傷、倒地、持有／未持有狀態。每組最多十二條，可選全部／任一符合；空條件不限制。數值支援等於、不等於、大於／小於及含等號比較；布林與分類只支援等於／不等於。
- 搜尋方式：自身、最近單體、正對面、全體、自身＋左右鄰居、最低 HP 數值／比例、最高失衡、隨機一人。自身／鄰居限我方；鄰居須緊貼佔位邊緣。僅選活角色。最近同距離隨機，其餘排名同值取最左側。
- 角色行動、極式與法則被動的「最近單體」共用施放角色攻擊距離（含我方搜尋）；全體、隨機、最低 HP、最高失衡等方式不限距離。「正對面」限敵方佔位重疊，按條件篩選後選最近一人，同距離取左側；不回退搜尋。普通移動、互換與跳躍維持位置搜尋規則，不受攻擊距離限制。互換／跳躍最多一組單體，先排除無合法位置者。

「直接加快主動技能時間 N 秒」（advanceSkill）預設 1 秒，允許 0～10000 秒及一位小數。以自身為目標加快我方主動技能，同一項作用選取多名同陣營角色只計一次，最多提前至當下就緒，仍需手動施放。沒有可用技能或本場停用技能時略過。

「直接加快時間 N 秒」使用 `type:advance`、`amount:N`，預設 1 秒，允許 0～10000 秒與小數一位。直接將目標下次角色行動提前 N 秒，最多提前至當下就緒，不儲存超出的時間；最早在下一次 0.1 秒戰鬥更新時行動，每角色每次更新最多一次。原始行動間隔、極式冷卻及戰鬥時間不變，僵直仍阻擋行動。共用條件、目標與多作用順序，角色、極式及法則皆可使用，不套攻擊力或輸出加成。

副效果的目標搜尋新增「搜尋基準：主效果選中的目標」，選取方式為目標本身、左鄰、右鄰、左右鄰居（不含目標）、目標＋左右鄰居。主效果仍以施放者搜尋。可將主效果設為最近單體／傷害倍率 A，副效果設為主效果目標／左右鄰居／傷害倍率 B。基準保留主效果執行前實際選中角色的身分、陣營及完整佔位；目標死亡或後續移位不改變定位，不重新抽選。左右鄰居為同陣營、緊貼原佔位邊緣的存活角色，不跨空格、不受施放者射程限制，仍套用副效果目標條件。主效果多人時合併各基準結果並按實例去重；無鄰居只略過該副效果。施放者死亡／僵直仍中止後續效果。角色行動、極式及被動共用此搜尋，極式／法則維持只用常數項、不使用角色攻擊倍率。搜尋資料 base 可為 actor／main／event，預設 actor，excludeSelf 預設 false，可排除施放者，main 的 mode 為 target／left／right／neighbors／targetNeighbors；讀檔逐欄修復，舊設定保持原搜尋方式。移動、互換及跳躍不使用此基準。

被動效果另提供「搜尋基準：本次事件角色」（base:event），可在主／副效果選目標本身、左鄰、右鄰、左右鄰居、目標＋左右鄰居。例如「被治療時／敵方角色」搭配「本次事件角色／敵方／目標本身」，效果會作用於真正受治療的敵人；「治療他人時」則指治療者。每筆被動事件保存該角色實例、陣營及事件發生時的佔位，連鎖事件不覆蓋上下文；兩旁依原佔位邊緣判斷、不跨空格、不受射程限制，搜尋仍檢查指定陣營、存活及目標條件。角色已死亡時不對其本身作用，但仍可依原佔位找存活鄰居；無上下文或無符合對象時略過、不改選其他人，主效果失敗仍略過該被動的副效果。玩家極式事件以實際技能施放者為事件角色，既有全域觸發規則不變。僅被動編輯器顯示本次事件角色選項；普通角色行動／極式沒有此事件上下文，移動、互換及跳躍不使用此基準。舊檔未設 base 仍使用施放者搜尋，新增值與相關條件皆逐欄修復。

每組僅在開始時判斷一次 cond 並搜尋一次 targets，接著按 actions 順序，對已選中的所有目標逐一執行。後續作用不重判條件、不重新排名或補選目標；公式、狀態與倒地倍率讀取當下更新值。目標死亡後略過對它的後續作用，施放者死亡或僵直則中止其後作用。互換與跳躍共用原本的單體位置限制，不能放在同一效果組。

公式角色參照與基礎攻擊力的意義見「效果與公式」。每個受作用者獨立計算公式與隨機量。

底層使用有序 effects 陣列：effects[0] 是 main，effects.slice(1) 是 other；介面明示角色並可調整順序。不儲存兩份可能不同步的效果。舊空 effects 仍保留為無作用行動；編輯器建立角色時提供一個主效果。
跳躍效果 type 為 jump，無數值／公式，預設敵方最近單體且不限距離；可編輯目標條件與其他單體排名。落點是我方與敵人起始格同欄的位置，整段佔位須在界內且無其他活隊友。可跨越隊友、不受普通移動距離限制；已在對面（佔位重疊）時視為就位並接續效果，死亡隊友釋放格位但保留統計。先篩出有合法落點的敵人再排名。「落點被佔用時」預設不換位，可開啟換位備援。隊友須從落點格開始佔位，互換後雙方完整佔位均須合法。搜尋只排名可就位的敵人。原地就位不發送移動或互換事件，實際換位沿用互換事件。成功後立即依新站位執行副效果，主效果失敗則沿用移動分支。法則戰鬥被動也可執行此效果。

新效果使用 cond、condMode、targets、actions；actions 依序儲存各項作用的 type、amount，以及狀態的 status／duration，不另設條件或目標。每個 target 使用 base（預設 actor）、side、mode、excludeSelf（預設 false）、targetCond、targetCondMode（range 僅保留舊格式相容，不再決定效果距離）。角色另有 movement，預設敵方／最近／不限距離／空條件。缺少條件預設空陣列、組合預設 all。舊 targeting.filter 與 targeting.conditions 在編輯時轉為 targetCond；舊 when 與 legacyEnemy 條件已移除；嚴格儲存不接受，讀檔時列出修復紀錄，請重新確認發動條件。讀取不覆寫 localStorage，無效新欄位逐欄修復並列出紀錄；合法 0、false、空陣列保留。

角色與法則戰鬥事件已觸發執行，規則見「戰鬥法則被動」；升星、勝利、地圖移動、休息、購買與販賣事件已移除。超時環境傷害維持一次對雙方生效，仍可同時全滅平手。

### 戰鬥統計與逐筆飄字

「戰鬥統計／返回戰鬥結果」已共用現行紙面按鈕底圖，與速率同為48px高，寬156px容納長文字；切換時保留紙框。桌面與窄版皆維持原操作位置，獨立展示的重新試煉在統計顯示時另列於下方以免擁擠。

我方獲勝或平手後，戰鬥畫面提供「戰鬥統計」，按下後以開場十格站位顯示雙方全部角色（包含死亡角色），列出本場傷害、護盾、治療與行動次數；可切回戰鬥結束畫面。僅切換顯示，不更動血量、位置或重複結算獎勵。

傷害以效果結算量計，含護盾承傷、倒地倍率及溢出傷害；護盾為產生量，治療扣除溢補。反擊歸反擊者，持續傷害／恢復歸施加者，超時環境傷害不列入角色輸出。行動計真正開始的普通冷卻行動，包含移動與無目標等待，不計手動極式。角色以本場獨立 ID 區分，同名或重複角色不合併；死亡或被後續移動覆蓋格位也保留紀錄。

每筆傷害／治療／護盾使用獨立效果紀錄顯示粗體紅／綠／藍飄字，不用血量淨差計算；同時抵銷、護盾完全吸收、持續效果、反擊與超時也能顯示，重繪不重播，死亡後該筆飄字仍保留至動畫結束。

### 固定初始隊伍

Config 的初始出戰隊伍儲存為 `startingActive`，為十個角色 ID 或 null 的陣列。預設出戰為人類劍士、機人守衛、人類靈療師，依序放在前三格；儲存隊伍開局固定十格全空，沒有設定欄位。角色庫排序不影響編隊。

每格選擇固定角色，依角色起始星數出場；可重複放同一角色，每次配置建立獨立 instanceId。多格角色只填起始格，後續佔位保留 null 並顯示佔用來源。存檔與新旅程會檢查不存在的角色、重疊和超界；錯誤時提示修正，不自動補角、移位或換隊。出戰隊伍允許留空，但空出戰隊伍不能進戰鬥。

商品數仍受十格佔位限制；賣回金幣為 floor(角色售價 × 比例 / 100)。金幣／獎勵／商品數／傷害轉失衡可設 0。倒地承傷取四捨五入；傷害轉失衡先用倒地增傷前的傷害向上取整。混亂／鎮靜也使用 Config 失衡門檻。探索衰減設定統一位於蜂窩地圖。

## Config 設定與戰鬥超時

五個獨立參數為基礎戰鬥時間 X、扣血週期 P、初始每次扣血量 Y、成長間隔 A、每次成長量 G。預設 X=120 秒、P=1 秒、Y=10、A=10 秒、G=10。第一次扣血在 X+P 秒，之後每隔 P 秒扣一次；從第一次扣血起計時，每滿 A 秒增加 G，於扣血時點套用。第 n 次扣血時間為 X+nP，傷害為 Y+floor((n−1)P/A)×G。G=0 表示固定傷害。Config 表單即時列出前四次扣血時點與數值。

例如 X=120、P=2、Y=10、A=5、G=3，122／124／126 秒扣 10，128／130 秒扣 13，132 秒扣 16。預設仍為 121～130 秒每秒扣 10，131～140 秒每秒扣 20。

超時傷害同時對雙方每個存活角色生效、穿透護盾，不觸發反擊／激怒／失衡，先於同 tick 狀態與行動結算。同時全滅仍平手。儲存後既有旅程保持快照，下一局套用；完整 JSON 匯出／匯入包含 Config。

## 蜂窩地圖流程預覽

在工坊切換到「蜂窩地圖」，或開啟 editor.html#map。地圖採軸向六角座標，半徑可設定為 2～6（19～127 格），預設半徑 4／61 格。同一種子與大小會產生相同配置；「換一張地圖」產生新種子，「重置探索」保留地圖並回到入口。

點擊相鄰格即可直接前進，不再需要右側移動按鈕；方向鍵選取、Enter 或空白鍵前進。普通完成格仍可繞行與回頭；脆弱地板離開後崩塌，禁止再次踏入。工坊戰鬥仍需按預覽完成；營地抵達自動升級並消耗，商店在關閉視窗後消耗，完成事件不再觸發。終點位於入口對側，抵達後結束探索。

工坊預覽一開始只揭露入口與相鄰一圈；每次移動揭露當前格與其六個鄰格，已揭露的內容保留。完整地圖輪廓與終點始終可見，其他迷霧格不顯示節點類型。編輯器的「查看全圖」不會改變已揭露集合或允許跨格移動，取消後回到原探索進度。

工坊戰鬥按鈕僅模擬完成；營地自動提升預覽回響等級，商店可操作本次預覽的角色與法則交易。首頁進入的 play.html 已串接實際戰鬥、血量、商店與獎勵；兩者的探索進度皆不持久儲存。地圖預覽不修改角色或技能存檔。js/hex-map.js 負責地圖生成、移動與迷霧，js/map-editor.js 與 css/map.css 負責預覽。

## 地圖生成規格與獎勵衰減

地圖資源欄和商店重骰與水晶之間都顯示回響等級。滑鼠指向或鍵盤聚焦時顯示本局等級與 SR／SSR／UR 基礎機率，按當前回響權重換算。商店離開按鈕旁的問號開啟商店說明。戰鬥速率旁的問號開啟戰鬥說明，並暫停進行中的戰鬥，關閉後可手動繼續。

生成流程改為固定配額＋分布限制，不再逐格獨立抽事件。預設 61 格包含一般戰鬥 24、菁英 5、休息 5、商店 4、脆弱地板 6、空地 15，以及入口／終點各 1。其他大小按可用格數縮放配額；變更半徑會重填預設配額，也可自行修改。剩餘格自動成為空地，直接通行、不觸發事件或獎勵。

生成面板可設定五種配額（含脆弱地板）；新圖預設脆弱地板依大小縮放，舊存檔缺少或無效配額補 0 並記錄。脆弱地板只在離開後損壞，通行照常計回合；崩塌不寫入地圖設定，重置探索會恢復。菁英／營地／商店各自可設最小間距、休息與商店之間的最小間距，以及菁英距入口的最低步數。相鄰六角格距離為 1，設定 2 即禁止相鄰；入口安全範圍只排除菁英，不排除普通戰鬥或補給。補給點與菁英優先分散至較少使用的方位區域，此項為分布偏好；配額、距離與安全範圍則為硬限制。

同一大小、種子與規格會重現同一配置。生成器最多重試 160 次，找不到符合條件的配置時顯示錯誤並保留原地圖；不會減少配額或放寬限制。「本圖配置」顯示目前地圖，配額欄位則為尚未套用的草稿。

獎勵衰減取代舊探索警戒，敵人 HP 不再隨探索增加。設定存於地圖 rewardDecay：{enabled,stages:[{after,tier}]}，初始為全階級，after 表示距上一階段再經過幾回合；每列 1～999 回合、最多 10 列，可增刪，階級只能維持或下降。空階段陣列保留全獎勵。預設啟用，階段為 3→高、再 2→中、再 1→低、再 2→無，累積門檻為第 3／5／6／8 回合。

| 階級 | 金幣比例 | 角色獎勵 |
|---|---:|---|
| 全 | 100% | 3 選 1 |
| 高 | 80% | 2 選 1 |
| 中 | 50% | 1 選 1 |
| 低 | 20% | 無 |
| 無 | 0% | 無 |

只有普通敵人與菁英從首次實際揭露時開始計時；工坊全圖檢視不算揭露。成功移動一格計一回合，包含回訪、商店、營地及脆弱地板；無效移動、原地整備、領獎與戰鬥時間不計。新揭露當下為第 0 回合，進入敵人格的那一步也計回合，隨即鎖定階級；整備、敗北重試不再改變該格獎勵。BOSS 一律全獎勵。金幣為 floor(該類戰鬥基礎金幣 × 階級比例 / 100)，角色只改選項數，不改角色星等或回響抽選規則。低階級只確認金幣，不開角色視窗；無階級不開領獎視窗、直接完成結算。零獎勵格仍須戰鬥通過。

地圖格標示階級與金錢比例；滑鼠移入或鍵盤聚焦時，頂部提示當前角色選項數、距離下一階段的回合數及其金錢／角色幅度。工坊亦提供預覽。首次揭露回合與獎勵鎖定僅存在本局記憶體，不回寫編輯設定。

## 整備、成長與商店

完整玩法與資料邊界集中於 [局內成長與經濟規格](PROGRESSION_SPEC.md)，包含戰後三選一、手動合成、法則購買、回響等級、營地及商店重骰。

- **戰後領獎**：勝利依鎖定階級開啟金錢與角色入口；有獎勵的項目皆須完成，角色為免費 3／2／1 選 1，低／無階級不發角色。空間不足會警告，可先開整備，清空間後領同一批獎勵。
- **搬移與合成**：點擊角色查看資料；拖到空位搬移，拖到相同角色同星等時手動升一星（最高六星），其餘角色嘗試交換。合成繼承全部法則。拖起自有角色後，可合成卡會亮金框；移到其上會顯示脈動光暈、星形及「放開升星」與星等變化，拖曳卡同步淡化。移開或取消即清除提示；減少動態效果時改為靜態高亮。商品不顯示合成提示。
- **隨時販賣**：整備與商店頂部皆有賣出區，拖入自有角色出售，依 Config 比例返還金幣。
- **買角色**：商店角色分頁顯示商品、出戰與儲存三排；拖商品到隊伍空位購買，不自動合成。
- **買法則**：法則每次固定 4 個，正式商店左右各上下堆疊兩張，中央預留三格寬的裝備角色區，一／二／三格卡片依佔格等比置中；商品頂列集中圖案／名稱／價格，下方完整卡寬顯示敘述，整列高度維持與角色商品分頁一致。工坊維持原單行排列；窄版可橫向捲動；卡內顯示敘述，不另列「法則被動」。先拖入或指定裝備對象，再點卡購買（工坊預覽按「購買並裝備給○○」）。角色仍留在原位置，重複法則屬性累加；戰鬥被動已生效，非戰鬥時機已移除。法則數量不受 Config 的角色商品數上限影響。
- **重骰商品**：按商店的「重骰全部商品」一起替換角色與法則；價格依 Config，每店獨立累加，離店後商店事件消耗。
- **回響升級**：新旅程從一級開始，抵達營地自動免費升一級並消耗。後續商店與戰利品先抽階級，再依該階級角色權重抽角色。

整備可裝備符合出戰隊伍條件的極式，商店不顯示該欄位。正式旅程與工坊預覽各有自己的隊伍與金幣，均不回寫角色庫。

角色售價／階級內權重在角色分頁，法則售價／權重在法則分頁，階級比例在「回響等級」，角色商品數、賣回比例與重骰費用在 Config；法則固定每次 4 個。
工坊改完設定後，請重置探索再檢查預覽；正式旅程請重新開始遊戲。

## 首頁旅程串接

首頁「開始遊戲」→ play.html → 透視六角地圖。左上門圖示返回首頁，右上資訊列向內縮，同列顯示回響、水晶、整備與問號。拖曳角色時，出售區顯示水晶圖示及預計返還數值。探索操作、資源與戰利品衰減表集中在問號開啟的「旅程說明」，指向格子時，深色提示框只顯示獎勵階級，各階級比例見旅程說明。鏡頭以約 0.48 秒平滑跟隨隊伍移動，隊伍標記在畫面下方，初始朝向終點；格子越遠越壓縮。移動不自動旋轉，按住滑鼠右鍵左右拖曳可旋轉視角。每步揭露相鄰一圈，已揭露格子永久保留，只有尚未探索的格線與事件藏在霧中；鏡頭背後的格子轉回視角即可再見。戰鬥與商店在平移完成後開啟；迷霧以覆蓋整個地圖容器的雙層雲紋緩慢流動，中央路面較清楚、兩側與遠方自然淡入霧中，不會出現固定寬度的淺色背板；霧層不影響點擊、鍵盤操作或探索判定。前景霧沿已揭露區域與未知區域的交界生成，隨鏡頭移動及旋轉更新，並避開已知路面；只讓相鄰的第一圈未知格露出朝向已知區域的短邊，不顯示完整格形、事件或可點擊目標，更遠的未知格仍完全隱藏。系統減少動態效果設定會停用霧氣流動並跳過平移動畫。仍可六方向移動與回頭；方向鍵依畫面方向選取可見格子。角色素材尚未提供，隊伍暫用發光菱形標記。正常及脆弱地板採 A 款灰石，隨鏡頭旋轉及縮放。戰鬥、菁英、終點、營地及商店以朝向玩家的分色立板（灰褐戰鬥、暗紅菁英、黑黃 BOSS、深藍燭夜、孔雀綠商店）標示，同距離下菁英大於普通戰鬥，BOSS 最大。戰利品越少立板越暗。事件消耗後只留地板，脆弱格崩塌後顯示碎石缺口。正式旅程不常駐顯示事件說明側欄。

走入未完成戰鬥／菁英格會開啟實際戰鬥，使用目前出戰站位、所有出戰角色及所裝備的極式，每場重新以最大 HP 開始；儲存隊伍不參戰。戰鬥結束顯示 VICTORY／GAME SET 並等待點擊，勝利點擊後才結算金幣及開啟戰利品，完成全部領獎後可返回地圖；勝利及平手均消耗節點。敗北點擊後直接返回進戰鬥前一格，撤回該一步的步數、路徑及造成的脆弱地板崩塌，保留已揭露／訪問紀錄、原敵隊與鎖定獎勵，敵人格仍可重新走入挑戰。平手點擊後仍可查看統計，不退回前格。戰鬥中的移動不改寫整備站位。商店買賣與整備直接共用本次旅程的角色實例和金幣。

Config 預設獎勵：一般戰鬥勝利 +40 金幣；菁英勝利 +90；終點 BOSS 勝利 +150；一般／菁英按鎖定階級衰減金幣與角色選項，BOSS 維持全獎勵；完成應領項目後才能繼續，無階級直接完成。一般／菁英先依隱藏玩家等級適配，再於所選等級依權重抽選；BOSS 僅依權重。戰鬥傷害與死亡只影響當場，戰後不寫回角色血量，下一場所有出戰角色重新滿血。營地不補血，改為免費提升一級回響等級，最高依回響等級分頁設定，每個營地抵達即消耗，關閉商店也會消耗該商店；之後只能通行。敗北保留開戰前狀態，可整備後重試；平手不發獎但消耗戰鬥格，終點平手結束旅程。正式介面不提供撤退。結算以每次戰鬥 token 防止重複領獎。敵方不具備極式。擊敗終點 BOSS 後可開始新旅程。

遊戲頁不提供編輯器全圖檢視、生成參數或模擬勝利按鈕。工坊預覽維持獨立。開始旅程讀取已儲存角色與技能，讀取時逐欄補合法預設，不覆寫工坊存檔；探索進度目前僅保留在此頁面，重新整理／返回首頁會重置，尚無續玩存檔。主要程式為 js/journey.js（流程資料）、js/journey-ui.js（地圖及戰鬥串接）、js/journey-view.js（跟隨鏡頭與透視投影），共用 js/expedition-ui.js 與 battle.html。

## 編輯器資料與遊戲設定

- 角色基本屬性新增「商店販賣售價」與「角色出現權重（商店／戰利品）」，皆為 0～1000000 的整數。售價是玩家購買價，賣回依 Config 比例向下取整（預設一半）；權重 0 完全排除商店與戰利品，但不影響初始隊伍或敵隊引用。售價與權重都是必要欄位，資料格式為 v2。
- 商店在可容納的正權重角色中，先按回響等級抽階級、再按該階級角色權重抽取，允許重複角色，預設最多 8 件（由 Config 調整）且總佔位不超過 10 格。每個商店只開放一次，關閉後不能再次購物；仍在店內時可付費重骰。同階級角色相對權重例如 100：300，表示該階級被抽中且兩者皆能放入時，角色條件機率為 25%：75%；跨階級機率由回響等級決定。
- 蜂窩地圖「套用並儲存設定」保存半徑、種子、事件配額及間距至 minimajo.map.v1；獎勵衰減開關與各階段也保存。重新進編輯器會還原，下一次開始遊戲使用相同設定與種子。無效草稿不覆寫已儲存設定。衰減只影響獎勵，敵方能力不變。
- 新增「敵方隊伍」頁籤：可新增、命名、刪除、儲存十格隊伍，設定一般／菁英／BOSS 分類、適配等級與出現權重。引用角色 ID，允許相同角色重複編入；多格角色後續佔用格須留空。儲存檢查重疊與越界，遊戲檢查角色引用。資料保存在 minimajo.enemies.v1；沒有存檔時按角色庫產生三類預設隊伍，已有存檔則不自動補隊。
- 一般、菁英、終點各自抽選對應類別的正權重敵隊；同一節點重試保留第一次抽出的對手。分類無正權重隊伍或引用失效時明確提示，不改用硬編碼敵人。終點現在必須擊敗 BOSS 才通關，獎勵 150 金幣。所有模式的敵方隊伍都沒有極式。

上述設定於新旅程載入，既有旅程不即時更換地圖／角色／敵隊。請在同一瀏覽器儲存角色、敵隊與地圖設定，再由首頁開始新遊戲。遊戲進度本身仍不持久保存。

敵隊編輯器採左側隊伍清單、右側詳細設定。十個位置各自選角色與星數（起始星數至 6 星），並顯示 HP 與佔格摘要；相同角色可配置不同星數。敵隊資料新增十格 `stars` 陣列，`null` 代表使用角色起始星數，新建資料預設使用起始星數。提高角色起始星數後，低於起始星數的敵隊設定會提示修正，不偷偷降級或換隊。正式旅程與試打使用相同升星能力計算，新旅程保留載入時的成長快照。

### 敵隊快速隨機生成

敵方隊伍頁上方提供獨立的「快速隨機生成」區塊，與下方隊伍編輯表單分開。每按一次「生成新隊伍」即新增一支不同 ID 的隊伍並自動選取，清除清單搜尋以顯示新隊伍，不覆蓋既有陣容。新隊伍自動命名「隨機敵隊 N」，預設一般、適配等級 1、出現權重 100，可在下方修改；沒有任何隊伍時也能生成，最多 300 隊。生成失敗不新增或切換隊伍。原隊未儲存編輯與連續生成的隊伍均保留在本頁草稿，清單標示未儲存；按原有「儲存敵隊」只保存目前選取的一隊並同步固定檔案，不連帶儲存其他隊伍的草稿。切換時原有捨棄確認只影響目前隊伍，離頁仍會提醒尚有草稿。

- 角色 N 次：預設 20，允許 1～1000 整數。SR／SSR／UR 權重預設 60／35／5，各為 0～1000000 整數且至少一項正值，介面即時換算基礎機率。
- 每次先排除無法放入十格的新角色、已六星的重複角色，再按階級權重及階級內角色既有 shopWeight 抽選；兩種權重 0 都排除。缺少合法候選的階級排除後重新換算，故接近滿隊時實際比例可能改變。新角色由左側第一個可用連續空間放入，只保存起始格，其後佔位保持 null。
- 首次命中使用角色起始星數，之後同角色每次命中直接升一星，最高六星；這是編輯器生成捷徑，不改玩家同星合成規則。生成隊伍每種角色至多一名；十格已滿仍可升星，所有候選耗盡則提前停止並顯示完成次數，不強制填滿十格。
- 法則 M 次：預設 10，允許 0～1000 整數。角色生成完成後依法則 shopWeight 抽取（0 排除），每份等機率附加到一名角色，不按角色佔格加權；可重複抽同法則、連續貼同角色，每份保存獨立完整快照。M 大於 0 卻無可抽法則時報錯；沒有可抽角色時也報錯。
- 參數僅存在本頁，重載回預設，不新增敵隊存檔欄位或旅程動態生成規則。N／M 控制抽選投入量，不保證固定戰力。

驗證：tests/enemy-generator.test.js、tests/enemy-editor.test.js；tests/browser/enemy-generator.cjs 使用隔離 Edge 與暫存固定 JSON 驗證草稿、重生成、失敗保留、法則堆疊、儲存重載、參數重設及 1440／390px 版面，不改正式 JSON。

### 敵隊強度測試（背景循環賽）

工坊「敵隊強度測試」分頁（editor.html#enemy-tournament）可勾選 N 支已儲存敵隊，設定 M 輪（預設 10，1～1000 整數）。每輪每組不同隊伍只打一場，不與自己對戰，總場數為 N × (N−1) ÷ 2 × M。可選 2～300 隊，單次上限 100000 場，超出會提示減少隊伍或輪數。搜尋名稱／分類／適配等級後可全選搜尋結果，也能取消全選及重新讀取名單。權重 0、一般／菁英／BOSS 與各適配等級都可自由參賽，不使用旅程配對規則；空隊或無法建立合法陣容者停用並顯示原因。新生成及修改的敵隊須先儲存才列入。

- 開始時擷取已儲存角色（含職業／種族／階級加成）、敵隊星數、各角色完整法則快照、狀態庫及 Config，後續修改不影響本次測試。既有敵隊法則不會因法則庫更新而被替換。
- 共用 Battle.create／step 與 EnemyTeams.formation，十格完整佔位、狀態、被動及超時傷害均沿用正式引擎。每場重建滿血獨立實例，雙方都關閉極式；自動進行普通行動，不顯示戰鬥畫面、不發獎或更新旅程。
- 各組第一輪位置由本次隨機種子決定，之後逐輪交換雙方位置；偶數 M 時每組位置次數相同，奇數 M 時差一場。每場有不同的衍生種子供公式與目標隨機使用；沒有隨機效果的組合可能每輪結果相同。結果顯示本次種子，但本版未提供輸入種子或重播功能。
- js/enemy-tournament-worker.js 在 Web Worker 背景運算，主畫面可繼續使用／切換工坊分頁；請保持頁面開啟，關閉或重載會失去結果。執行時鎖定輪數及隊伍勾選，搜尋與兩兩成績查看仍可用；頁面顯示場數進度與部分排名。停止按鈕直接終止 Worker，只保留已回報的完整場次，正在運算及尚未回報的場次不計分。錯誤時提示並可重跑。
- 排名表列出場次、勝／敗／平手／未決、勝率與得分率。勝率＝勝場 ÷（勝＋敗＋平手）；得分率＝（勝＋平手 × 0.5）÷ 同一分母，依得分率由高至低排名、同率並列。未參賽或僅未決時顯示「—」。可指定一隊查看它對各對手的累計成績，勝敗以指定隊伍為準。停止、中斷或有未決時應留意樣本數不齊，結果僅代表本次參賽隊伍間的表現，不是固定戰力值。
- 基礎戰鬥時間結束後仍沿用 Config 的超時扣血；若模擬到「基礎時間＋3600 秒」仍未結束，列為未決，不偽裝平手、不納入勝率／得分率。Worker 可隨時停止，避免特殊回血／被動配置長時間卡住整批作業。

選取、輪數與結果僅為本頁暫態，不新增存檔欄位，不改寫敵隊、固定 JSON 或旅程。驗證：tests/enemy-tournament.test.js；tests/browser/enemy-tournament.cjs 使用隔離 Edge／暫存資料實測深連結、篩選與選隊、權重 0／空隊、真實 Worker 循環賽精確統計、對手視角、停止／重跑、Worker 錯誤復原及 1440／390px 版面。

## 戰鬥法則被動

角色固有被動與法則共用編輯卡及事件佇列，每名角色最多二十條被動，每條最多八組效果。角色固有被動可設持有者攻擊力倍率，法則被動只設公式與常數。事件角色條件篩選「誰引發事件」，作用的目標搜尋另行設定。relation 可設自身、同陣營（含自己）、敵方或任意角色，特殊時機依下表鎖定。

| 時機 ID | 事件角色與觸發範圍 |
|---|---|
| action | 開始普通行動的角色，包含之後移動或等待的行動 |
| attacked | 受到正值敵方直接傷害者，護盾吸收仍算，包含極式、被動與反擊 |
| heal／healed | 實際治療量大於 0 時的治療者／受治療者，持續恢復也計入 |
| shield／shielded | 產生正值護盾時的施放者／接受者 |
| down／death | 實際進入倒地／首次死亡者，不限制致因 |
| move | 實際移動者，含走路、跳躍與互換雙方 |
| swapInitiated／swapReceived | 自身發起／接受互換，事件範圍固定自身 |
| swapped | 每次成功互換一筆，以發起者為事件角色，可監聽敵方 |
| playerSkill | 玩家使用極式，扣 CD 後、效果前通知雙方存活持有者，略過事件角色範圍與屬性條件 |
| allySkillResolved | 我方極式及其連鎖結算後，固定同陣營，事件角色為施放者，無命中仍算有效施放 |
| dodged | 消耗閃避成功者，同次普通行動只發動一次 |
| normalHit | 普通行動對敵人造成正值直接傷害時的攻擊者，護盾吸收仍算，閃避／反擊／持續／被動／極式排除 |
| normalDown／normalKill | 普通行動直接使敵人倒地／死亡，只通知造成結果的持有者，事件角色固定該敵人 |
| statusGained | 每次施加狀態的接受者，包含首次、同名刷新與永續累加 |

共十九種時機。normalDown／normalKill 只計 CD 到時普通行動的直接主／副效果，傷害造成的失衡與直接增加失衡均可造成倒地，反擊、持續效果、被動、極式及超時排除。statusGained 下方可設不限、正面、負面或指定狀態，先依收到的狀態判斷，再配合事件角色條件。狀態分類在狀態分頁編輯，自訂預設中性。

事件於觸發時檢查條件並排入先進先出佇列，同事件按我方到敵方、角色配置順序、固有被動到法則份數及被動欄位順序處理。同一普通行動或極式及其連鎖內，每名角色每條固有被動、每份法則每條被動最多發動一次。下一次獨立行動可再觸發，持續狀態與超時依既有批次開啟連鎖。

被動由持有者施放，主效果失敗則不接副效果，也不嘗試普通移動，不消耗普通行動 CD。僵直持有者略過一般被動。死亡被動允許剛死亡者對存活角色作用，其他已死亡旁觀者略過。每筆普通作用結束後處理連鎖，被動自身的主副效果依序完成後再處理衍生事件。全部死亡連鎖結算完才判勝負，可造成平手。輸出歸實際施放者。

原 starUp／victory／travel／rest／purchase／sale 六種非戰鬥時機已移除，舊檔逐條略過並列修復紀錄。欄位預設與相容處理集中在 js/saved-data.js。

## 隱藏玩家等級與敵隊適配

新旅程有隱藏 playerLevel，從 1 起算；每場有效勝利結算加 1（包含無戰利品與 BOSS），敗北／平手／重複 token 不增加，不因領獎或整備變動。新旅程重設，不在玩家 UI 顯示。敵隊 matchLevel 預設 1，允許 1～1000000 整數；缺少／型別錯誤／超界時逐欄補 1 並列出紀錄，備份保留。首次進入普通或菁英戰鬥時，先按分類排除權重 0 與空隊，再選適配等級與玩家等級差距最小者；上下同距離取較低等級，僅在該等級內依出現權重抽選。BOSS 完全不依玩家等級，僅按原權重。各格敵隊抽出後存於 enemyRolls，整備／戰敗重試不重新匹配；只選既有敵隊，不自動調整角色能力。編輯器左側可搜尋名稱及精確適配等級，兩條件交集；填等級時排除 BOSS，清空顯示全部，搜尋不清除表單草稿。BOSS 的適配欄位停用。

## 法則編輯與敵隊配置

「法則」分頁採左側名冊、右側表單，可新增、搜尋、複製、刪除及逐筆儲存。空資料庫會顯示新增引導。永久屬性使用數值欄位，被動以「觸發時機 → 角色範圍與全部符合條件 → 效果」卡片編輯；效果共用條件與目標／狀態設定，但數值只提供常數項運算群組與常數整數，不使用角色攻擊力或倍率。`minimajo.laws.v1` 儲存 `{version:1,laws:[]}`。
每筆 `{id,name,description,imagePath,shopPrice,shopWeight,stats,passives}`；售價與出現權重為 0～1000000 整數，0 售價表示免費，0 權重排除商店抽選。舊資料缺少或無效欄位逐欄補為售價 50、權重 100，列出補值紀錄，讀取不覆寫原存檔；表單儲存嚴格驗證。stats 欄位與職業升星相同。被動格式為 `{when,subject:{relation,conditions},effects}`。
relation 為 self／ally／enemy／any，conditions 為全部符合的 `{field,value}`，支援種族、類型、職業、階級、星數。
when 支援 action／attacked／heal／healed／shield／shielded／down／death／move／swapInitiated／swapReceived／playerSkill／dodged／normalDown／normalKill／normalHit／statusGained／swapped／allySkillResolved。原非戰鬥時機 starUp／victory／travel／rest／purchase／sale 已移除；舊檔載入略過該條被動並列出紀錄，不影響同角色／法則的其他被動。
極式基本設定新增 `imagePath` 圖案路徑，預設空白；使用與法則相同的專案相對路徑及 240 字限制。表單儲存、複製、逐欄讀取修復、完整備份、技能選擇與旅程快照都保留。戰鬥按鈕在冷卻環內顯示所選技能圖片，空白或載入失敗沿用原符號，冷卻環、名稱提示及施放操作維持原規則；圖案由各技能 imagePath 指定。

剪紙疊影極式素材已放在assets/ui/ultimate-icons/v1/，共7原版與9變體；在編輯器填例如assets/ui/ultimate-icons/v1/04-A.png，不能只填04-A.png。完整可貼用清單見該目錄paths.txt。圖片本身透明、不含按鈕圓框；各技能使用哪張圖由編輯器設定，素材安裝不會自動改寫技能資料。

狀態編輯器同樣提供敘述 description 與圖案路徑 imagePath，兩欄預設空白，限制與法則相同；狀態儲存、複製、狀態庫快照及完整備份均保留，無效欄位逐項補預設，不影響合法效果規則。角色技能、極式、法則與狀態的敘述框共用滿寬、字級、內距及垂直縮放樣式。狀態圖片只讀各筆imagePath；22筆定案路徑已填入固定JSON，因此編輯器可見。使用者可換成任意合法圖片路徑；清空或缺圖時顯示通用符號，不依狀態ID恢復預設圖。缺少欄位仍依規格補空字串，不偷偷補入圖片。

法則編輯器可填「法則敘述」與「圖案路徑」，兩者預設空字串。敘述最多 2000 字、保留換行；圖案路徑最多 240 字，使用專案內相對圖片路徑（例如 `assets/laws/example.png`），支援 PNG／JPG／WEBP／GIF／AVIF／SVG，不接受外部網址、絕對路徑或上層目錄。商店法則卡顯示名稱、價格、圖案與敘述；未設定或載入失敗時保留圖案槽。讀檔時兩欄各自補預設，不影響合法欄位；完整備份、購買及裝備快照保留敘述與圖案路徑。修改法則庫後，既有旅程與已配置快照依原本規則保持原資料。

敵隊每格 `laws` 保存完整法則快照，可加入／移除；同一角色可重複加入同一法則，每份快照獨立保留、移除，永久屬性逐份累加後套用既有能力上下限（角色持有份數不再限制為 100，以完整保留合成繼承）。法則庫的定義 ID 仍維持唯一；隊伍讀檔、備份匯入及戰鬥均保留重複法則。先套星級成長，再套法則屬性；屬性會帶入戰鬥。傷害／治療／護盾增量加到角色行動與固有被動的各類攻擊力後再乘技能倍率，不套用至極式或法則被動，戰鬥數值運算群組與常數整數在最後相加。例如攻擊力 20、傷害 +30、倍率 2、群組 rand(10,20)、常數整數 3，結果為 113～123；倍率 0 則只剩 13～23。職業／法則增量存於本局 outputBonuses，iframe 驗證後保留，不改寫基礎效果或儲存 amount.bonus。失衡增量同存 outputBonuses.posture，於失衡效果量結算時相加；狀態施加量另取狀態層數加成。
戰鬥被動已接入共用引擎，工坊試打、獨立展示與正式旅程戰鬥使用相同規則。升星、勝利、地圖移動、休息、購買與販賣事件仍只保存設定，編輯器選單及商店說明標示「尚未支援」。局內可於商店購買法則並直接裝備給指定角色；其他取得途徑與局內移除流程尚未實作。
職業成長只包含升到 2～6 星的五列，不存在 0 星或升到 1 星設定。

## 狀態視覺化資料庫

狀態可設 classification 為 positive／negative／neutral，分別供獲得狀態事件及淨化篩選。內建依用途補值，自訂預設中性。固定資料的六種永久累加狀態以「永續」顯示，ID 仍為 enhanced 系列，缺庫時的程式預設仍採舊名稱。

嘲諷（taunt）為固定啟用、無強度數值的一般狀態，可設秒數或角色行動次數，同名刷新、不疊層。僅影響 CD 到時普通行動對敵方的最近單體、最低 HP 數值／比例、最高失衡與隨機一人搜尋：先套原目標條件，再找施放者攻擊距離內、存活且持有嘲諷者；優先選最近者，同距離隨機。無合法嘲諷者沿用原搜尋，不縮減最低血量／隨機等原本不限距離的搜尋範圍。距離沿用完整佔位計算。正對面、全體、我方搜尋、主效果目標／本次事件角色及其左右鄰居不改選；移動、互換、跳躍、被動及手動技能不受影響。每組搜尋獨立選取，組內全部作用共用結果；主／副效果都適用。內建狀態庫新增嘲諷，舊庫讀取逐欄補入並列修復紀錄；其規則固定 value:1，不能使用倍率、公式或強化累加，狀態編輯器鎖定相關欄位。未新增或替換正式狀態圖示。

頂層「狀態」分頁提供名冊、搜尋、新增、複製、名稱與效果卡片編輯。內建 21 種狀態（含嘲諷、閃避與六種永續狀態）以預設資料提供；混亂增加失衡，鎮靜降低失衡，激怒受擊時推進行動進度。
每個狀態可組合 1～8 條作用：每秒 HP／失衡增減、傷害／治療／護盾攻擊力修正、普通攻擊反擊、受擊進度推進、僵直及速度調整。 治療增減使用 healing／healingWeakness，可在狀態效果種類中選取並建立自訂狀態。
數值模式為施加量倍率、固定值或視覺化公式；速度比例 0.5 代表 50%，受擊進度以秒設定並換算成 0.1 秒 tick，其他數值取整。速度總倍率限制 0～10。激怒預設固定 1 秒，每筆正值敵方直接傷害觸發一次（護盾承傷及技能亦算），中毒與反擊不觸發；以傷害結算前的狀態為準，死亡不推進，進度最多到就緒，最早下一 tick 行動。
公式 self／enemy／target 均指狀態持有者，time 暫為 0；不支援施加者引用。一般狀態持續時間在角色／極式／被動效果中設定，通常可選秒數或角色行動次數。舊設定若為一般永久狀態，載入時補為 1 秒並列出修復紀錄；含速度效果僅限秒數、閃避固定 1 次敵方普通攻擊、永續狀態（enhanced）固定永久。狀態編輯頁明示限制與是否強化，效果編輯器鎖定受限制的持續方式並隱藏不需填寫的數值。
保存鍵 `minimajo.statuses.v1`，格式 `{version:1,statuses:[{id,name,description,imagePath,classification,enhanced,effects:[{behavior,scale|value|formula}]}]}`。原角色／技能存檔仍引用狀態 ID。
狀態選單儲存後更新、工坊試打重置；旅程開局保存狀態庫快照並隨戰鬥訊息傳入 iframe。已附加狀態也保存作用規則快照。
目前不提供刪除狀態，以避免角色／法則的引用失效；狀態庫包含在統一備份中；新建與複製後須儲存才加入名冊。角色與法則被動已接入戰鬥事件執行。

### 互換位置行動效果

效果編輯器新增「互換位置」，可用於角色行動、極式與法則效果資料。僅選同陣營存活單體，排除自身；沿用最近、隨機、最低血量、最高失衡與狀態篩選，屬性與戰鬥狀態條件統一放在各搜尋組的 targetCond，最多十二條，可選全部／任一成立；所有效果共用。互換沒有數值／公式欄位。先依全部條件篩選，再以最近、最低血量、隨機等方式選取。
先排除無法交換的候選人，再依選取方式挑一人。交換雙方起始格，寬度不變；不能超界、互相重疊或占到第三名活隊友，無合法目標就略過。只互換站位，不交換陣營、血量、狀態、冷卻、角色身分或統計，也不另外增加行動次數。互換作為主效果時，找到合法交換對象即可執行並接續副效果；無合法對象則走移動分支。作為副效果時無對象只略過自己。互換立即改變位置，其後的效果依新位置搜尋。
法則新增 `swapInitiated`（自身主動互換位置時）與 `swapReceived`（自身被互換位置時），事件角色固定為自身。這兩種時機已執行觸發；交換雙方也各觸發移動事件。
