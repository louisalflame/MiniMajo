# 極式圖案素材庫

2026-11-07，使用者要求將透明切圖放到assets，方便在編輯器使用。16枚512px PNG從docs/ui-style/ultimate-icons-cutouts-v2/icons/原樣複製，與來源位元組相同。

在極式的「圖案路徑」填完整專案相對路徑，例如：

```text
assets/ui/ultimate-icons/v1/04-A.png
```

圖案清單見 manifest.json 的 file 欄位；使用時加上 assets/ui/ultimate-icons/v1/ 前綴。02／04／11／15／16／18／20是原版，A是簡化、B是繁複；原版16的完整路徑是assets/ui/ultimate-icons/v1/16.png。

已安裝圖案素材，尚未替使用者指定哪個技能使用哪張圖，也沒有修改固定JSON。原稿、原始解析度切圖、去背檢查與生成提示留在docs/ui-style/對應目錄。manifest記錄來源與SHA-256。
